# Claw 主页声音

原创合成音频，不使用外部采样或现成音乐。背景音乐由 `tools/Compose-HomeAudio.mjs`、界面音效由 `tools/Compose-UiSounds.mjs` 确定性生成。

- 轻触：柔和的触感短音，适合长时间浏览。
- 清透：轻微泛音与清亮的确认音。
- 数码：经过柔化的电子音色，保留掌机操作的节奏感。

每套 22 个事件，照 Steam 大屏幕的那一套划分：导航、到头、确认、返回、进 / 出详情、启动游戏、页签、侧边菜单（控制中心）进 / 出、弹层（设置类页面）开 / 关、开关开 / 关、滑块上 / 下、提示、成功、出错、打字、开机、截图。播放走自带的小混音器（waveOut），几个声音可以叠着响；导航 30 ms 限流、相邻两下音高错开，打字随机微调音高。

0.1.67 音色重制：移除按键的高通白噪声和切页的噪声扫频，改用带限泛音、短共鸣敲击和连续相位滑音。所有声音的起音和收尾归零，回声逐次吸收高频；常用导航保持干净、短促。三套风格和 22 个事件的文件名保持一致，背景音乐不变。

`tools/Compose-UiSounds.mjs` 的 `THEMES` 定义音色，`CUES` 定义每个事件。修改后运行 `node tools/Compose-UiSounds.mjs` 即可更新全部 66 个 WAV；不需要安装第三方依赖。`Sfx/sfx-manifest.json` 记录音效时长、峰值和 RMS。

运行 `node tools/Preview-UiSounds.mjs` 可在 `artifacts/ui-sound-preview/` 生成三套试听；第二个参数可以指定旧版 Sfx 目录，生成先旧后新的对比试听。

三首主页背景音乐均无歌词、无鼓点；使用扩展和弦、稀疏短旋律和立体声回响，尾音按循环长度回卷：

- 浮光：72 BPM，53.33 秒，柔和明亮的电钢琴与合成铺底。
- 星港：66 BPM，58.18 秒，疏朗的钟音与空间感。
- 夜航：60 BPM，64 秒，低饱和、偏安静的夜间氛围。

背景音乐默认关闭、独立音量默认 20%，在前端失焦或启动游戏时淡出暂停，回到前台后淡入续播。自定义音乐只复制到应用自己的音乐目录，不移动原文件；导入时经过系统解码校验。

`audio-manifest.json` 记录音频的采样率、时长、峰值、均方根电平与循环边界数据。
