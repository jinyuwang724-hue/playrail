# Claw 主页声音

原创合成音频，不使用外部采样或现成音乐。背景音乐由 `tools/Compose-HomeAudio.mjs`、界面音效由 `tools/Compose-UiSounds.mjs` 确定性生成。

- 轻触：柔和的触感短音，适合长时间浏览。
- 清透：轻微泛音与清亮的确认音。
- 数码：经过柔化的电子音色，保留掌机操作的节奏感。

每套 22 个事件，照 Steam 大屏幕的那一套划分：导航、到头、确认、返回、进 / 出详情、启动游戏、页签、侧边菜单（控制中心）进 / 出、弹层（设置类页面）开 / 关、开关开 / 关、滑块上 / 下、提示、成功、出错、打字、开机、截图。播放走声音引擎 miniaudio（0.11.25，公有领域 / MIT-0；`Native/ClawAudio`，构建时编成 `clawaudio.dll`）：音效整段解码进内存，几个声音可以叠着响（同一种最多两层），总线软限幅防削波；导航 30 ms 限流、相邻两下音高错开，打字随机微调音高。音效和背景音乐共用一个 WASAPI 设备、分组调音量，没有声音一秒后设备停掉。

0.1.221 高清重制：48 kHz / 24 位立体声（与 Windows 默认混音格式一致，加载不重采样）。
- 音高语法：以 A5 为主音，确认 / 打开 / 开 = 上行，返回 / 关闭 / 关 = 同一组音的镜像下行；成功 = 大三和弦琶音，出错 = 低八度小二度双击下沉，到头 = 闷的低音轻沉；滑块上高下低。控制中心从左边滑出，它的进出声相也从左到中。
- 跨设备：能量集中在 600 Hz–5 kHz，180 Hz 以下切掉（掌机喇叭放不出，只会让功放提前削波），低音靠泛音暗示；8–14 kHz 只留很轻的空气感。立体声合成单声道几乎不损失。
- 响度按 K 计权分六档（打字最轻、导航、次要、确认、提示 / 出错 / 成功、启动 / 开机），整体与 0.1.67 持平，峰值 ≤ −1 dBFS，TPDF 抖动到 24 位。
- 音色：轻触 = 毡头马林巴（调音木条泛音），清透 = 玻璃钟片（非整数泛音 + 轻微拍频），数码 = 干净正弦 + 二三次谐波。

`tools/Compose-UiSounds.mjs` 的 `TIMBRES` 定义音色，`CUES` 定义每个事件，`LEVEL` 定义响度档。运行 `node tools/Compose-UiSounds.mjs` 即可更新全部 66 个 WAV；不需要第三方依赖。`Sfx/sfx-manifest.json` 记录每个音效的时长、最大瞬时响度和峰值。

运行 `node tools/Preview-UiSounds.mjs` 可在 `artifacts/ui-sound-preview/` 生成三套试听；第二个参数可以指定旧版 Sfx 目录，生成先旧后新的对比试听。

三首主页背景音乐均无歌词、无鼓点；使用扩展和弦、稀疏短旋律和立体声回响，尾音按循环长度回卷：

- 浮光：72 BPM，53.33 秒，柔和明亮的电钢琴与合成铺底。
- 星港：66 BPM，58.18 秒，疏朗的钟音与空间感。
- 夜航：60 BPM，64 秒，低饱和、偏安静的夜间氛围。

背景音乐默认关闭、独立音量默认 20%，在前端失焦或启动游戏时淡出暂停，回到前台后淡入续播。淡入淡出在引擎内按采样做。自定义音乐只复制到应用自己的音乐目录，不移动原文件；MP3 / WAV / FLAC 直接用，M4A / AAC / WMA 导入时用系统编解码器转成 MP3（旧版导入的副本启动时自动转换），导入后试解码校验。

`audio-manifest.json` 记录音频的采样率、时长、峰值、均方根电平与循环边界数据。
