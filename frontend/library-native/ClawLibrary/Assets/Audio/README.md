# Claw 主页声音

原创合成音频，不使用外部采样或现成音乐。背景音乐由 `tools/Compose-HomeAudio.mjs`、界面音效由 `tools/Compose-UiSounds.mjs` 确定性生成。

## 界面音效（0.1.222 起，全新设计）

一套签名音色，22 个事件（照 Steam 大屏幕划分），`Sfx/claw/*.wav`，48 kHz / 24 位立体声，与 Windows 默认混音格式一致，加载不重采样。

声音只用三种材料，每种只代表一类意思：

- **触**（移动）：干、短、有质感的"嗒"（瞬态 + 高 Q 共鸣）。导航、页签、滑块、打字、到头、快门。
- **光**（状态变化）：会滑音的 FM 纯音。往上滑 = 确认 / 打开 / 开，往下滑 = 返回 / 关闭 / 关。
- **气**（空间变化）：带共振峰和声相的气流。页面浮上来是吸气往上，退下去是呼气往下；控制中心从左边出入。

提示和成功用玻璃铃，出错用闷的嗡声，这两种音色别处不用。调式 D 利底亚，主音 D6；签名动机 D–A–E 用在启动游戏和开机。

播放端：在墙上移动时声相跟着焦点在屏幕上的横向位置走，撞到左 / 右边界就在那一侧响；滑块的音高跟着数值在区间里的位置走（±半个八度）。

工程：150 Hz 以下切掉（掌机喇叭放不出）；K 计权响度六档（打字 < 移动 < 次要 < 状态变化 < 结果 < 时刻），峰值 ≤ −1 dBFS；小板混响 + 窄立体声，单声道兼容；TPDF 抖动到 24 位。

`tools/Compose-UiSounds.mjs` 生成全部文件（`CUES` 定义事件，`LEVEL` 定义响度档），不需要第三方依赖；`Sfx/claw/manifest.json` 记录时长、最大瞬时响度和峰值。

播放走声音引擎 miniaudio（0.11.25，公有领域 / MIT-0；`Native/ClawAudio`，构建时编成 `clawaudio.dll`）：音效整段解码进内存，可叠（同一种最多两层）、可变调、可摆声相，总线软限幅；导航 30 ms 限流、相邻两下音高错开，打字随机微调音高。音效和背景音乐共用一个 WASAPI 设备、分组调音量，没有声音一秒后设备停掉。

## 背景音乐
三首主页背景音乐均无歌词、无鼓点；使用扩展和弦、稀疏短旋律和立体声回响，尾音按循环长度回卷：

- 浮光：72 BPM，53.33 秒，柔和明亮的电钢琴与合成铺底。
- 星港：66 BPM，58.18 秒，疏朗的钟音与空间感。
- 夜航：60 BPM，64 秒，低饱和、偏安静的夜间氛围。

背景音乐默认关闭、独立音量默认 20%，在前端失焦或启动游戏时淡出暂停，回到前台后淡入续播。淡入淡出在引擎内按采样做。自定义音乐只复制到应用自己的音乐目录，不移动原文件；MP3 / WAV / FLAC 直接用，M4A / AAC / WMA 导入时用系统编解码器转成 MP3（旧版导入的副本启动时自动转换），导入后试解码校验。

`audio-manifest.json` 记录音频的采样率、时长、峰值、均方根电平与循环边界数据。
