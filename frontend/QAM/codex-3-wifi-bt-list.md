# 任务：快捷面板内的 Wi-Fi / 蓝牙列表页

## 参考
- 仓库内的交互参考见 [Wi-Fi／蓝牙原型](../../docs/quick-access/qam-network-demo-20261106.html)。
- 初稿和配套截图保存在本地 `frontend/QAM/`。
- demo 只是视觉和交互规格。代码按仓库现有结构写：WinUI 3 C# + Composition，NativeAOT，快捷面板在 `frontend/library-native/ClawLibrary/Stage/WallStage.QuickPanel.cs` / QamWindow，主题在 `Stage/Chrome.cs`，弹簧在 `Gfx.cs` / `Engine/Motion.cs`，图标在 `Stage/LineIcons.cs`。不要照搬 demo 里的 HTML 或 JS。
- 基线是游戏库 0.1.243。 [早期交接记录](../../docs/archive/toolbox-2026-10/CLAUDE_HANDOFF.md)

## 入口与导航
- 快捷面板左下 3×3 里的 Wi-Fi、蓝牙格：A 仍然直接开关。进入列表页：在格上按 →，或者长按 A / 长按触摸（与现有网格的约定保持一致；如果已有 Y 进入的约定，就沿用）。
- 列表页在面板内部替换网格以上的内容，**不另开窗口**。网格视图向左退 56 px 并淡出，列表从右推入 56 px，用 420 ms、cubic-bezier(0.22,1,0.36,1)（等同 Motion.cs 里的 camera 曲线）。返回时动画对称，可以中途打断。
- B 返回：依次关闭屏幕键盘、取消「再按一次」的确认、收起行内展开，最后回到网格，焦点回到原来的格子。
- 在列表行上按 ← 也返回（行内有展开或焦点在开关上时除外）。
- 上下移动时，同一行里的水平项（行本体和 ⋯，标题 ‹ 和开关）算一个整体。左右在行内切换。

## 布局（面板宽 416，1280×800 逻辑像素，设备上 ×1.5）
- 状态栏不变。内容从 y=76 开始，左右各留 32。
- 标题行 52 高：「‹ Wi-Fi」或「‹ 蓝牙」，24/700。右侧开关 46×28，圆角 9（圆角方形，不用胶囊）。
- 分组标题 13/600，55% 白，36 高，上间距 12。扫描中时右侧显示三个 4×4 方块依次闪烁，扫描完成后隐藏。
- 列表行 56 高，左右各外扩 12，圆角 14：
  - 左边 24 的线性图标。Wi-Fi 是 4 段信号格，未达到的段为 25% 不透明；蓝牙按设备类型显示 手柄 / 耳机 / 鼠标 / 键盘 / 音箱。
  - 名称 15/600，过长时用省略号截断。副行 12/400，55% 白，只在有信息时显示。
  - 右侧：锁图标（加密网络），⋯ 按钮 32×32、圆角 11（只出现在已连接或已保存的项上）。
- 焦点用小焦点：行底色 9% 白，不画整框。⋯、‹、按钮获得焦点时用白底黑字。开关获得焦点时用双环。全页只有一种焦点语言。
- 忙碌状态：行底部 2 px 进度条，副行显示「正在连接…」「正在断开…」「正在配对…」。

## Wi-Fi 页
- 分组：已连接（一行，副行「已连接 · 5 GHz」）、可用网络（按信号强度排序）。
- 副行文案只用这几种：已保存 / 个人热点 / 开放网络 / 正在连接…。没有可说的就不显示副行。
- 在已保存或开放网络上按 A：直接连接，显示忙碌状态，成功后移到「已连接」，toast「已连接 X」。
- 在加密的新网络上按 A：行下展开（高度弹簧动画）密码框和「取消 / 连接」按钮，焦点进入密码框并弹出屏幕键盘。
  - 屏幕键盘贴屏幕底部，横向从 x=448 到右边留 32，不盖住面板。可以用系统触摸键盘，前提是能定位到这个区域并且支持手柄；做不到就自己画。
  - 密码框右侧的眼睛图标切换显示 / 隐藏。
  - 键盘上的「完成」把焦点移到「连接」。X 键是退格。
  - 密码错误时，在框下显示「密码不正确」，保持展开。
- 在已连接或已保存的项上按 ⋯：展开「断开」（仅已连接时）和「忘记此网络」。忘记需要按两次 A，第二次按钮变红显示「再按一次忘记」（#FF5A4E，与退出游戏的确认一致）。
- 开关关闭时，下面的列表全部隐藏，只剩标题行。

## 蓝牙页
- 分组：我的设备（已配对）、其他设备（扫描结果逐个出现，每行淡入并上移 8 px）。
- 我的设备：A 连接或断开，副行「已连接 · 电量 80%」或「未连接」。⋯ 里有「断开」和「忘记此设备」，忘记需要两次确认。
- 其他设备：A 开始配对。
  - 需要数字比较（Numeric Comparison / Passkey）的设备，在行内展开「确认两边显示的配对码一致」和大号 6 位码（32/700，三位一组），以及「取消 / 配对」，焦点默认在「配对」。
  - Just Works 的设备直接配对。成功后移入「我的设备」并显示已连接。
- 开关关闭时同 Wi-Fi 页。

## 系统接口
- Wi-Fi：`Windows.Devices.WiFi.WiFiAdapter`（`ScanAsync`、`NetworkReport`、`ConnectAsync`，带 `PasswordCredential`），已保存的配置用 `Windows.Networking.Connectivity` 或 WLAN API（`WlanGetProfileList` / `WlanDeleteProfile`）判断和删除。需要 `wiFiControl` capability。
- 蓝牙：`DeviceInformation.FindAllAsync` / `DeviceWatcher`（`BluetoothDevice.GetDeviceSelectorFromPairingState`），配对用 `DeviceInformationCustomPairing`，处理 `PairingRequested`（ConfirmPinMatch / ProvidePin / ConfirmOnly），连接和断开用对应的 profile。如果某类设备只能由系统发起连接，在报告里写清楚。
- 开关复用现有的 `Windows.Devices.Radios` 逻辑。
- 所有操作都不能卡住 UI 线程：乐观更新加写队列，复用快捷面板现有的写队列机制。失败时回滚，并用 toast 给出简短原因。

## 约束
- 文案克制：不加提示文字，不加按键提示栏，每个字都要承载信息。不跳转 Windows 设置。
- 只用圆角方形，不用圆形（滑块旋钮除外）。颜色只用 Chrome.cs 的 Theme：#09090B / #F4F4F5 / 55% / 8% 填充，红色只用于不可逆确认。
- 触摸和手柄都要能完整操作。
- 升级安装 ClawToolbox.Library，不要先卸载。版本号递增。不碰 Clash Verge。

## 验收
- 真机上 Wi-Fi：连接已保存网络、输入密码连接新网络、密码错误、断开、忘记。蓝牙：连接或断开已配对手柄 / 耳机，配对新设备（数字比较一次，Just Works 一次），忘记设备。
- 进出列表页的动画用实际速度录屏，确认不掉帧、可打断、左右对称。
- 游戏前台时操作列表页，游戏不失焦（面板仍然是不激活窗口）。屏幕键盘输入不会把按键漏给游戏。
- 汇报时分清真机测试和构建 / 日志。
