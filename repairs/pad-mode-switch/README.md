# 手柄 / 桌面模式切换（2026-11-13）

设备上的后台 0.17.58.2 是在安装目录里直接打补丁出来的，和仓库 `plugin/` 不一致，所以这次的后台改动按同样方式打在安装目录上，补丁脚本和差异放在这里，等后台源码合回仓库时一起合。

## 问题

- 从 Game Bar 小组件切不回手柄模式：桌面模式下打开 Game Bar 时，后台临时把手柄借成手柄模式（好用手柄操作 Game Bar）。小组件读到这个临时状态，第一下点击变成「切到桌面」，要点两次。
- 切换慢：
  - Game Bar 关上后小组件被挂起，不再读连接。后台每次推送事件都要等它 2 秒超时，一次切换推送 2 次，实测约 4 秒。
  - 每次切换都同步重读整个手柄固件、重写摇杆死区和 M1/M2，0.2–0.6 秒。
  - 快捷面板切到桌面时，会先固定等待 400 毫秒。

## 改动

后台（`patch_agent.py`，差异见 `agent-0.17.58.2.diff`）：

- `claw_agent.py`：推送事件不再让调用方等待。每个前端的发送各自在后台执行，同一连接内仍按顺序。
- `claw_service.py`：
  - 记住「你选的模式」，`get_gamepad_state` / `widget_state` 多返回 `chosen` 和 `held` 两项。
  - 新增 `toggle_gamepad_mode`，按你选的模式一次切到位。
  - 模式提示改为不等待。
- `claw_input_layer.py`：切换时先让新布局生效，固件微调（死区、背键、键位）在后台按顺序做；桌面键位缓存，手柄页写固件时作废。
- `claw_gamepad_fw.py`：固件模式没变时不再整套重新写入；手柄一次没回应时，读写各快速重试一次。

小组件 0.4.73：调用 `toggle_gamepad_mode`；按 `chosen` 显示图标；遇到旧后台时退回原来的做法。

游戏库 0.1.268：快捷面板去掉 400 毫秒等待；按 `chosen` 显示；收到模式事件时同步更新。

## 结果（实机）

- 后台切换：0.4 秒（挂起的小组件在时约 4 秒）降到 35–130 毫秒。
- 小组件：桌面模式下打开 Game Bar，图标显示键鼠，点一次 0.2 秒回到手柄；再点一次回到桌面。

## 安装和回退

- 安装：`python patch_agent.py <原文件目录> <输出目录>`，把输出的 4 个文件放进 `%LOCALAPPDATA%\ClawToolbox\app`，再重启 `\ClawToolbox\Agent` 计划任务。
- 原文件备份在 `%LOCALAPPDATA%\ClawToolbox\repair-backups\app-0.17.58.2-before-padmode`。
- 注意：「设置 › 安装或更新后台」会用游戏库安装包里的后台覆盖这次的补丁。
