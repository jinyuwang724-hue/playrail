## 视觉与节奏

沿用用户选定的双页轮廓，以及 `assets/branding/README.md` 中“冷白、冷灰，不使用黄色”的约定。用可直接绘制的矢量重建双页，去掉应用图标的圆角底块。

- 进入：画面压暗，双页出现；两侧光弧与少量细光向内收束，双页沿中央书脊折叠，留下细光后落到纯黑。主动画 1150 ms，随后预留 32 ms 提交黑帧，再发起原来的电源操作。
- 唤醒：纯黑上的细光出现，双页反向展开，细光向外扩散；黑底整体平滑淡出，均匀露出原画面。没有圆形开口或空间擦除。950 ms 后动画层完全透明并关闭。
- 无声音、无全屏白闪。渲染回调只在动画期间订阅，黑屏等待恢复时不绘制帧。不会在真正睡眠时维持动画。

`TransitionScene.cs` 是运行时与离线帧预览共用的绘制器。`SleepOverlay.cs` 提供窗口、时序和黑帧提交；实体按键信号、策略接管、看护进程、设置协议未改动。若桌面切换使合成帧停止，动画等待有上限，不会因此无限保留遮罩。

## 开机与关机的覆盖范围

当前运行时只在睡眠／休眠恢复通知中触发唤醒动画，冷启动登录后不会自动播放。没有新增开机、关机或注销触发。

同一视觉可以复用于用户登录后的开场，以及工具箱主动发起关机／重启前的收场。前者需要单独登录触发并区分 S4 恢复，后者需要在工具箱自己的关机请求交给 Windows 之前播放。当前只是能力判断，没有实现这些新触发。

普通用户桌面的动画窗口不能覆盖 UEFI／厂商 Logo、Windows 引导、登录安全桌面，以及系统已结束用户会话后的关机画面。微软的 [Unbranded Boot 文档](https://learn.microsoft.com/en-us/windows/configuration/unbranded-boot/) 描述的是隐藏特定 Windows 启动界面；受支持的启动 Logo 替换涉及 UEFI BGRT，不能据此把桌面动画扩展成全程开机动画。本次没有调整引导或登录设置。

收到 `WM_QUERYENDSESSION` 后，应用应及时响应，并在 `WM_ENDSESSION` 中退出。故意拦截任意来源的系统关机来强播动画，可能出现系统的“应用阻止关机”界面，不能保证流畅完整。参见 [WM_QUERYENDSESSION](https://learn.microsoft.com/en-us/windows/win32/shutdown/wm-queryendsession)。
