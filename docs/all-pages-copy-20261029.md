# 其余页面文案统一

在 0.1.176 系统页试点基础上，将相同规范扩展到当前原生游戏库。构建源码位于 `artifacts/all-pages-copy/src/frontend/library-native`；修改遵循 [界面文案规范](ui-copy-guidelines.md)。

| 页面 | 调整 |
| --- | --- |
| 设置列表 | 删除无操作含义的行号；状态放在选项前；开关统一右对齐；不可用原因保持可读。 |
| 通用 | 简化自启动和后台操作名称，删除常驻的托盘重开教学行。 |
| 游戏库设置 | 将多行重复的生效说明合并到游戏来源分组；重新载入入口显示待生效状态。 |
| 外观 | 使用“封面灯光屏保”“封面切换间隔”等名称表达功能，删除重复解释。 |
| 声音与反馈 | 删除试听按钮的音效枚举和常驻格式列表；播放范围保留简短说明。 |
| 账户与服务 | 云端配置显示状态；网页入口不重复解释“打开网页”。 |
| 小黄鸭 | 简化检测、运行与未保存状态，保留程序名、错误及配置复制关系。 |
| 性能显示 | 删除常驻的档位循环教学行和悬浮窗实现说明，直接使用位置、缩放、档位控件。 |
| 性能 | 精简 CPU 和风扇状态；保留重启要求、温控保护、曲线编辑提示及恢复范围。 |
| 显示与声音 | 使用统一列表布局；保留 XeSS 使用条件、驱动错误和不可用状态。 |
| 手柄及映射子页 | 删除“照 Steam 输入”、开发批次和重复解释；保留组合键操作、当前映射及生效场景。 |
| 单游戏设置与添加游戏 | 使用统一列表布局；保留配置范围、文件、匹配信息、封面和确认操作。 |
| 截图 | 删除空状态的截图来源教学段落；保留筛选恢复、元数据和删除确认。 |
| 首次设置 | 使用“首次设置”“设置完成”替代问候及氛围文案。 |
| 游戏库、控制中心、快捷设置、窗口切换、正在游戏 | 保留已有的功能名称、游戏和窗口信息、实时状态及必要按键操作；它们已以结构和图形为主，不添加说明段落。 |

旧前端主目录比实际安装版本早，因此没有用旧目录整包构建。候选从与安装版可执行文件完全一致的 0.1.176 源码构建，保留既有功能及安装载荷；主目录仅应用能够匹配的相同局部补丁。完整变更与未匹配的旧源码片段记录在 `artifacts/all-pages-copy/integration.json`。

`tools/Prepare-AllPagesCopy.py` 保留基线、候选、补丁和哈希，支持在基线未变时重新准备。安装复用 `tools/Install-SystemCopyPilot.ps1 -Directory artifacts/all-pages-copy`，按记录校验版本、源文件、签名和原有偏好。

## 验证记录

**0.1.177.0 已原地安装**，安装包签名有效。通用设置 6 项、小黄鸭配置 20 项现有测试通过；安装后的原生输入检查 55 项通过；中文和英文各 16 个页面，共 32 组布局检查通过，没有被检标签与控件重叠或行内状态截断。4 份原有界面偏好文件哈希保持一致。

[实机前后对比](../artifacts/all-pages-copy/comparison.html)。`tools/Verify-AllPagesCopy.py` 核对变更范围、后台命令、英文条目、安装证据、运行检查和偏好文件，结果保存在 `artifacts/all-pages-copy/verification.json`。既有安装载荷、字体及其他资源保持一致；构建仍有原有手柄选择器 AOT 与符号包工具警告。

`--copy-review-probe` 使用真实页面构建方法检查显示、性能、系统和 13 个设置分类的中英文控件边界；不执行行操作、选项回调或硬件写入。测试源码位于 `tests/UiCopyReview/WallStage.CopyReviewProbe.cs`。其他未被实际访问的交互路径以源码审查和公共组件回归为依据，不将它们算作完整实机操作测试。
