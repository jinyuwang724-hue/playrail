# 系统页 · 功能点（待确认）

2026-10-20。版式照原生「性能」「显示与声音」页：左 3 右 7。
- 左栏是读数：电量大数字、充电 / 放电功率、剩余时间（或充满还要多久）、电池健康度、工具箱版本。
- 右栏是分组设置列表，按键和其他页一样：A 确认，Y 恢复默认，B 返回。
- 这一页的设置都只有全局一份，没有「当前游戏」。

「后台」一列说明这项功能后台现在有没有：
- 有 = 后台已经在用（Game Bar 小组件或性能浮层在读）。
- 新写 = 要给工具箱后台加接口。

3. **MSI / Intel 驱动和 BIOS 的「最新版本」先不做**：要去 MSI 和 Intel 官网抓，不稳定；先只显示当前版本。
4. **充电上限**要写 MSI 固件。先只读出当前值，实测写入安全、重启后还在，再开放调节。
