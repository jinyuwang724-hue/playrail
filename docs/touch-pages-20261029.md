# 全页面触控交互

以已安装的 0.1.177.0 文案精简版为基础，接入公共触控处理并补齐各页面的操作入口。最终安装版本与验证结果见 `artifacts/touch-pages/verification.json`。

已安装 0.1.179.0。65 项页面触控逻辑检查、55 项原有输入检查、32 组中英文布局和 42 项公共手势及保存队列检查全部通过；四份界面配置校验一致。

| 页面 | 触控行为 |
| --- | --- |
| 游戏库、集合、展开卡、搜索 | 点击进入、拖动浏览；主页增加控制中心图标入口，子层增加返回入口 |
| 控制中心 | 点击卡片和功能坞；横向滑动切换卡片；返回游戏库 |
| 性能、显示、系统、软件设置 | 点击开关与选项、纵向滚动；数值先点击进入调整，再拖动滑条或点击箭头 |
| 手柄、映射与触发设置 | 点击分类、映射、键格和页签；滑动换页；长列表滚动 |
| 单游戏设置 | 共用设置触控；修正嵌入式手柄子页的坐标换算、列表滚动；齿轮进入触发设置 |
| 添加、编辑游戏 | 点击字段、分类和封面；匹配结果及分类长列表可以滚动；隐藏内容不接收点击 |
| 截图 | 点击页签、缩略图和大图操作；日历纵向滚动，轮播横向切换；增加筛选、布局图标及筛选列表滚动 |
| 快捷设置 | 点击磁贴；亮度、音量、功耗滑条支持拖动；音量图标保留静音操作，右上角关闭 |
| 窗口切换 | 点击卡片、滑动切换；窗口标题右侧增加关闭图标 |
| 首次设置、启动提示 | 操作改为松手触发；输入框继续使用原生文字输入 |

每次手势只由第一根手指接管。拖动后不会再次触发点击；其他手指、指针取消，以及按下后发生的页面或目标替换，不会提交旧操作。快捷设置的连续数值修改会合并并按顺序保存，保留禁用状态与错误反馈。

验证包含公共手势测试、实际 WinUI 页面处理器中的内存测试、原有输入行为回归、中英文布局回归和窗口中的点击、拖动检查。亮度、音量、功耗通过内存通道验证，没有在检查过程中写入硬件；未使用物理触屏注入。结果和界面截图保存在 `artifacts/touch-pages/`。

完整可构建源码在 `artifacts/touch-pages/src/frontend/library-native/`；可重放的源码差异保存在 `tests/TouchPages/touch-pages.patch`。工作区根目录源码早于已安装版本，保留其已有修改，避免用旧源码覆盖正在使用的功能。`tools/Prepare-TouchPages.py` 可从 0.1.177.0 对应源码重建候选，`tools/Verify-TouchPages.py` 核对源码、差异补丁、配置及运行验证结果。
