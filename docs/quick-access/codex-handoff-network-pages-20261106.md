# 交给 Codex：快捷面板 Wi-Fi / 蓝牙列表页（设计 + 实现说明，2026-11-06）

**交互原型（以它为准）**：`docs/quick-access/qam-network-demo-20261106.html`（浏览器直接打开；在线版 https://claude.ai/artifact/RqiTBfAQ9yRLkVhseLNBXH ）。
原型键位：Q 开合面板；网格焦点在 Wi-Fi / 蓝牙格上按 **Y**（或长按格子）进列表；↑↓ 选、Enter = A、X 忘记、Esc = B。
页面顶上那行键位说明只属于原型，**界面里不出现任何按键提示**（用户规定：不要提示栏、不加说明文字）。

基线：游戏库 0.1.243（main），快捷面板代码 `frontend/library-native/ClawLibrary/Stage/WallStage.QuickPanel.cs`，
面板窗口 `QamWindow.cs`（常驻、不激活、透明；面板在合成层上用弹簧滑入）。构建 / 安装照 `docs/quick-access/codex-handoff-qam-20261106.md` 开头。

---

## 1. 入口与进出

- 面板网格里 Wi-Fi、蓝牙两个格子：**A = 开关**（现状不变），**Y = 进列表页**，触控长按格子（≥ 450 ms）= 进列表页。
- 列表页是面板里的**二级页**：同一个 416 宽的左侧栏、同一块冻结帧玻璃底。进入时主内容向左移 28 % 并淡出，列表页从面板右边推入
  （0.42 s，曲线 cubic-bezier(.22,1,.36,1)，实现用合成层动画，不在 UI 线程逐帧画）。B 返回同样的动画反过来，焦点回到原来的格子。
- 列表页打开时面板外的游戏照常显示，不压暗；面板窗口仍不抢前台（输入走游戏库的手柄轮询，和面板主页一样）。

## 2. 版式（设计 px，1280 × 800 逻辑尺寸，掌机 ×1.5）

- 内边距和主页一致：上 24、左右 32；内容宽 352。
- **页头** 36 高：‹ 返回图标（20，次文字色）+ 标题「Wi-Fi」/「蓝牙」22 / 700 + 右侧开关。
- **开关**：46 × 28 胶囊；关 = 8 % 白底、白色圆点在左；开 = 92 % 白底、深色圆点在右（0.3 s 弹过去）。焦点 = 外圈 3 px 深色隔开 + 3 px 白环 + 柔光（和网格格子的焦点同一套）。
- **分组标题** 34 高、上方留 18：13 / 600、次文字色（Wi-Fi：「当前网络」「其他网络」；蓝牙：「我的设备」「可配对的设备」）。正在扫描时分组标题右侧一个 14 px 转圈。
- **列表行** 48 高：左侧 22 的图标位（Wi-Fi = 4 格信号柱 3 px 宽、高 6/9/12/15，有信号的白、其余 22 % 白；蓝牙 = 设备类型线条图标：手柄 / 耳机 / 键盘 / 其他），
  间距 12，名字 15 / 400（单行，最长 200 宽，超出省略号），右侧状态 13 / 400 次文字色右对齐（宽 96），加粗部分用主文字色。
  - Wi-Fi 状态：加密网络一个 14 px 锁图标；「已保存」；连接中 = 转圈 +「正在连接」；当前网络 =「**已连接** · 5 GHz」。
  - 蓝牙状态：「**已连接** · 80%」（有电量就显示）、「未连接」、转圈 +「正在连接 / 正在断开 / 正在配对」。
- **空状态**：「附近没有可用的网络」「没有找到新设备」，13 / 400 次文字色；开关关掉时只显示「Wi-Fi 已关闭」「蓝牙已关闭」。
- 配色只用 Theme：底 #09090B、字 #F4F4F5、次文字 55 %、关闭底 8 % 白；红 #FF5A4E 只用于二次确认和密码错误这句；不用强调黄。字体 SF Pro + 苹方，数字等宽。

## 3. 焦点（小焦点，和面板主页一致）

- 焦点在行上时，**只有名字变成白底深色字的小胶囊**（左右内边距 10、高约 26、4–8 px 柔光），整行不加底、不加框。
- 焦点在开关上：开关的白环 + 柔光。
- 需要二次确认的动作（忘记网络、忘记设备）：第一次按下名字胶囊变红、文字换成「再按一次忘记」；第二次才执行；B 或移开焦点取消。
- ↑↓ 在页头开关和各行之间走（跨分组连续）；在顶上再按 ↑ 不动（轻微回弹音）；← 在行上 = 返回（和 B 一样）。

## 4. Wi-Fi 页行为

- 进入页面立即扫描（开关开着时），已知网络先显示，新扫到的逐个淡入（每个约 260 ms 间隔，0.3 s 上移 6 px 淡入）；扫描结束转圈消失。页面开着时每 10 s 静默重扫一次，列表原位更新，不跳焦点。
- **当前网络**一行：A 在下面展开一排胶囊按钮「断开」「忘记」（34 高、圆角 17，焦点 = 白底深字），←→ 在两个按钮间选；「忘记」要二次确认。
- **其他网络**：
  - 开放网络或已保存的网络：A 直接连接，行内显示转圈「正在连接」，连上后它移到「当前网络」，原来的当前网络回到列表并标「已保存」，toast「已连接 xxx」。
  - 加密且没保存：A 后面板**底部升起输入块**（深色实底 96 %、顶部 1 px 10 % 白线，0.42 s 升起）：网络名 17 / 700、「输入密码」13 / 400、
    46 高的输入框（焦点 = 2 px 白边，占位「至少 8 位」，右侧眼睛图标切换显示 / 隐藏，手柄 X 也能切）、错误时一行红字「密码不对，再试一次」、
    底部「取消」「连接」两个胶囊（不足 8 位时「连接」变暗不可按）。输入用系统触摸键盘 / 游戏模式下可用的键盘（游戏模式保留 explorer，TextInputHost 可用）。
  - 连接失败（密码错、超时）：输入块不收起，清空并显示红字；其他失败 toast 一句原因。
- 开关：关掉 Wi-Fi 后列表清空只留「Wi-Fi 已关闭」；打开后自动扫描。

## 5. 蓝牙页行为

- **我的设备**：已配对设备。A = 连接 / 断开（行内转圈过渡），X = 忘记（二次确认，确认后移到「可配对的设备」）。连接后有电量就显示。
- **可配对的设备**：进入页面开始发现（Bluetooth Classic + BLE），逐个淡入。A = 配对：
  - 不需要确认的：行内「正在配对」→ 成功后移到「我的设备」并连接，toast「已配对 xxx」。
  - 需要核对数字的（ConfirmPinMatch / DisplayPin）：底部升起同样的块，标题「与 xxx 配对」、说明「确认对方显示的是同一组数字」、
    34 / 700 等宽大号数字（每 3 位一组）、「取消」「配对」。需要输入 PIN 的设备同样用输入框。
- 开关：关掉后只显示「蓝牙已关闭」。

## 6. 后台 / 系统接口建议

- 开关：继续用 `Windows.Devices.Radios`（面板主页已在用：`QsRadio`）。
- Wi-Fi 列表 / 连接：`Windows.Devices.WiFi.WiFiAdapter`（`RequestAccessAsync`、`ScanAsync`、`NetworkReport.AvailableNetworks`、`ConnectAsync(network, reconnectionKind, credential)`、
  `Disconnect`）；当前连接用 `NetworkInformation.GetInternetConnectionProfile()` / `WlanConnectionProfileDetails`。
  注意：Win11 24H2 起读 SSID / 扫描可能要「位置」权限，打包应用要在清单里声明 `wiFiControl`、`location` 能力并检查用户是否允许；
  拿不到时给出明确提示（打开 设置 › 隐私 › 位置），不要静默空列表。「忘记网络」WinRT 没有直接接口：用 `netsh wlan delete profile name=…`（后台执行）或 WLAN API `WlanDeleteProfile`。
- 蓝牙：`DeviceInformation.FindAllAsync / CreateWatcher`（`BluetoothDevice.GetDeviceSelectorFromPairingState(true/false)`、BLE 同理）、
  `DeviceInformation.Pairing.Custom.PairAsync(DevicePairingKinds.ConfirmOnly | ConfirmPinMatch | DisplayPin | ProvidePin)`（`PairingRequested` 事件里弹核对块）、
  `UnpairAsync`。连接 / 断开音频设备可用 `Windows.Media.Audio` 的 `AudioPlaybackConnection` 或后台调 `BluetoothDevice` 服务；做不到的类型（例如键盘）就只显示状态，不给假按钮。
  电量：`DEVPKEY_Bluetooth_Battery`（`System.DeviceInterface.Bluetooth.Battery` 等属性）读得到才显示。
- 所有写操作走面板现有的写入队列思路：界面先变（乐观），系统调用在后台线程，结果回来再以系统状态为准；扫描回来的数据不能把正在操作的那一行覆盖掉。

## 7. 验收

- 截图逐像素对照原型：页头、分组、行高、右对齐、焦点胶囊、开关、底部输入块。
- 真速录屏：进出列表页、扫描逐个出现、连接 / 配对过程、输入块升起收回，帧时间无明显卡顿。
- 手柄全程可用（不需要触控）；触控也能点行、点开关、长按格子进入。
- 实测：连一个已保存网络、输入密码连一个新网络（含输错一次）、断开 / 忘记；蓝牙配对一个手柄或耳机、断开再连、忘记。
  如实写明哪些是实机连通验证、哪些只是界面验证。
