# Game Bar 快捷功能区 3 列 × 4 行（2026-10-18）

小组件版本 `0.4.15.0` 已构建、签名并更新到本机。

- 功能区保持 3 列，在原有区域内均分为 4 行，默认显示 12 个按钮。
- 原有九个按钮保持顺序，第四行增加已有的目标帧率、CPU 频率、风扇全速功能。
- 已保存的原九宫格排列会一次性扩展并保留其顺序；之后编辑、移除磁贴不会反复触发迁移。其他自定义组合保持原样。
- 编辑页面、上下移动的列数使用相同常量；原有其他可选磁贴继续保留。
- Game Bar 窗口的默认宽高、最小/最大尺寸、缩放设置均未更改。每个按钮的高度由原区域重新分配。

验证：Release x64 编译、安装包签名验证通过；本机包版本确认 `0.4.15.0`。源码中的窗口 Size 节点与修改前完全一致。通过原生窗口实测，在更新前相同的 `803 × 634` 窗口中，原 3×3 已变为 3×4，第四行完整可见；另检查了最大化显示。此处尺寸是独立窗口截图尺寸，不代表 Game Bar 覆盖层尺寸；未在本次复测实体手柄导航。
