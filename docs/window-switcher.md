# 窗口切换页（游戏库 0.1.168）

游戏模式没有任务栏，这一页就是任务切换；桌面模式也能用。源码在 OOBE 快照里，补丁 `artifacts/ws/window-switcher.patch`（基于快照 0.1.166）。

- **入口**：控制中心功能坞「窗口」；「正在游戏」面板第 4 个按钮「窗口」。快捷键待定（Claw 键只有一个 WMI 事件，分不出长按）。
- **列表**（`Data/OpenWindows.cs`）：Alt+Tab 规则——可见、未被 cloak、非工具窗口 / 不激活窗口、没有所有者（或带 WS_EX_APPWINDOW）、有标题；去掉我们自己、Game Bar、外壳宿主、输入法、osk。包含最小化的窗口。正在玩的游戏排第一，其余按 Z 序。每秒刷新一次。
- **卡片**：DWM 实时缩略图（`DwmThumb`，压在我们窗口内容上面，所以焦点描边在卡框外一圈）；最小化的窗口没有画面，卡里放 96 px 应用图标。卡下一行 = 图标（exe 里 128 px 的，取不到用窗口图标）+ 标题。
- **操作**：← → 选、A 切过去（正在玩的游戏走「继续游戏」；其余 `LibraryWindow.BringForward`，最小化的先还原）、X 请它关（WM_CLOSE，不强杀；管理员窗口收不到，会提示）、B 返回；点卡 = 选 / 切，左右划 = 换。
- **动效**：逐帧趋近的滚动与进出场（可打断），卡片依次浮上来，出场倒着走；缩略图同一帧挪。
- **自测**：`--state=ws`（打开停住）、`wsnav`（走两格回一格再出场）、`wsgo` / `wsx` + `--window=<标题片段>`（切过去 / 关掉）。

没有 explorer 时 Alt+Tab 仍能切窗口，但看不到切换界面（2026-10-29 实测）。
