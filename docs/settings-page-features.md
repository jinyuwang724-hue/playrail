# 设置页 · 功能点（2026-10-20 已确认，已实现）

2026-10-20。这是工具箱自己的设置，是一个**独立的整页**：控制中心的「软件设置」块和游戏库竖栏的 ⚙ 都打开它。它不再是竖栏里的小列表，也不跳到 Windows 设置。

「后台」一列说明这项功能现在有没有：
- 有 = 已经能用（多数在竖栏小列表或别的页里），只是搬过来。
- 新写 = 要新做。

## 页面结构（单独设计，不套 3:7 读数页）

- **左栏是分类目录**：通用、游戏库、外观、声音与反馈、游戏中、开机自启、第三方软件、维护、关于。
  - 用大号字，焦点在哪个分类，右边就跟着换。
  - 每个分类下面一行小字写摘要，比如「标题样式：电影字幕 · 7 个集合」。
- **右栏是这个分类的全部选项**，控件和其他页一样：开关、几选一、滑条、按钮。
  - 改过、和默认不同的项，前面有一个小点。
- **按键**：
  - 十字键 ↑↓ 选，左右切到目录或内容；A 确认，B 返回；Y 恢复本项默认。
  - LB / RB 不拿来切页，和其他页一致。
- 背景、焦点框、切换动效都用控制中心那一套，不另起一套视觉。

## 实现时的取舍

- 手动加的文件夹游戏暂时没有封面（显示色块和标题）。
- 语言只有简体中文，English 之后做。
- 来源、显示隐藏的游戏要「重新载入游戏库」后生效（页面里有按钮，会重启前端）。

## 不放这页

- 功耗、风扇、性能浮层：在性能页。
- 手柄按键映射、QS / Claw 键：在手柄页。
- 亮度、声音、显卡：在显示与声音页。
- 电池、驱动更新：在系统页。
