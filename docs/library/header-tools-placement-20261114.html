卡盒版顶栏入口摆放

建议：五个入口仍然连成一组放在右上，但按「工具 | 身份 | 系统状态」分三段；搜索从放大镜原地向左展开成输入框。

入口：搜索、添加游戏、Steam、设置、头像。下面四个方案按 1920×1200 的展台首页缩小画，白框是手柄焦点。

参考：主机和掌机前端怎么放

前端做法
PS5 主页左上是「游戏 / 媒体」页签；右上一组：搜索、设置、头像、时间，连在一起。手柄从内容区往上按就进这一排。
Steam 大屏幕 / Steam Deck顶栏右侧：搜索、通知、好友头像、电量、时间连成一组；系统菜单收在 Steam 键里。
Xbox 主页左上头像；右上时间和电量；搜索、设置做成内容区里的磁贴，或者收进指南键菜单。
Switch 主页左上用户头像，右上时间、网络、电量；系统入口是游戏行下面一排圆形图标。

共同点：页签留在左边；系统类入口靠右，紧挨时间电量；头像放在入口和状态之间，或者单独放在左边。只有 Switch 把入口放在底部，因为它的游戏行在屏幕中间。

样式切换的问题已经找到：在设置里从海报墙切到别的样式后，退出设置时切换动画被跳过了，所以设置里记的是新样式，屏幕上还是海报墙。这个修复不受方案选择影响，会和动画一起装上。
