# 游戏库原生版：对照与实测（2026-10-14，MSI Claw 8，1920×1200 @150%，60 Hz）

代码在 `frontend/library-native/`。WinUI 3 只做窗口，墙面全部画在 Microsoft.UI.Composition 视觉层上，
相机 / 缝 / 让位 / 翻牌 / 波次动画都在合成线程跑；NativeAOT，自包含 MSIX，用 CN=ClawToolbox 签名。

## 实测

- 冷启动（AOT MSIX，封面缓存已生成）：进程启动 → 第一帧 483–640 ms（中位约 525 ms），屏上封面全部解码约 0.75–1.0 s
- 首次启动另需约 10–11 s 在后台从 Steam 原图生成封面套件（期间墙正常显示，封面逐张出现）
- 帧间隔（`bench.json`，DWM 合成时间戳）：右摇杆平移、十字键走位、展开 / 收起、换页签波次、进出合集全部 p99 = 16.67 ms（60 Hz 每帧都到）；整轮只有 1 个 33 ms 帧
- CPU：静止 0.05–0.2 %，动画中 1–2.3 %（占全部核心）；GPU 3D：静止 0 %，动画中 2–5 %
- 内存：启动后工作集约 210 MB（私有 155 MB），来回翻几个页签后约 340 MB（封面缓存）

## 与网页版的差别

- 集合信息条的「共 N 小时」读的是本机 Steam 时长（网页版没读，显示 0）
- 「Narcissu 1st & 2nd」显示 &（网页版把 `&amp;` 原样显示了）
- 新的让位不会把上一次没走完的卡冻在半路（网页版快速连按时会）
- 颗粒噪点是近似（网页是 soft-light 混合）；边缘标签没有滑入动画；鼠标悬停效果没做
- 启动游戏仍是占位提示（与网页版相同）

## 2026-10-14 第二轮：动态背景与可交互竖条

**背景**：去掉了颗粒噪点（之前用随机噪点拉伸近似 soft-light，放大后成了斑点）。改成参照 folia 首页墙后面那层 visualizer
（「common」模式）的机制自己实现：底色 + 15 个缓慢漂移、自转的几何形（圆 / 方 / 三角 / 叉，七成描边三成实心，
不透明度 11–19 %，30–60 s 一圈）+ 20 个往上飘的光点 + 暗角；颜色取自当前焦点游戏的主色。墙是实色的，缝是 folia 的
「始终透明」材质（底色 64 % 的纱、上沿淡渐变、两侧发丝线），背景从缝里透出来。全是合成线程的循环动画；
缝合上、窗口不在前台、60 秒没操作、关掉动态背景或降低动态效果时暂停（原地冻住）。

**竖条**（首页窄缝 120 px，从上到下）：时间 + 电池 → 竖排页签（放不下全名时缩成一个字，再放不下在里面滚）→
分隔线 → 合集直达入口（竖排短列并排）→ 头像 + Windows 用户显示名 → 搜索 / 设置 / 文件管理器。LB/RB 提示去掉了。
- 焦点能进竖条：墙上横着走、下一张跨过缝时进竖条，落在离那张卡最近的一项；竖条里上下按行走、左右出竖条回到墙上
  那一侧离得最近的卡。焦点在竖条里时那一项白色描边高亮，墙上的焦点环熄掉。B 先关设置 / 搜索，再回墙上。
- 页签：A 换页签（整墙波次）；合集入口：A 打开合集；头像：打开 Windows「你的信息」；文件管理器：打开资源管理器。
- 设置（竖条里展开）：标题样式、动态背景、降低动态效果、性能读数。
- 搜索：竖条里出一个输入框（XAML TextBox，支持中文输入法），按名字过滤当前页签，墙翻牌换成结果。
- 鼠标点竖条里的项同样生效。

截图：`rail-focus.jpg`（焦点在竖条的账户项上）、`rail-settings.jpg`（设置展开）。

**实测（AOT MSIX）**：`bench-rail-backdrop.json`——走位、平移、展开 / 收起、换页签、进出合集全程每帧 16.7 ms，
整轮只有 2 帧 33 ms。静止时动态背景在动：CPU 约 0.7 %、GPU 3D 约 1.3 %；60 秒无操作后暂停：CPU 0.03 %、GPU 0 %。
（只有缝里那一条在动时 DWM 会隔帧合成，约 8 % 的帧 33 ms；角落加一个 1 px 一直在动的点后每帧准时，背景暂停时它也停。）
