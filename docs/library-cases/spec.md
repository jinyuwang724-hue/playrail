# 游戏库：卡盒版（实现规格）

> 2026-11-04 19:20 修订（用户实机反馈后）：
> - 展架：选中卡盒固定在最左（x=96），信息区左对齐叠在它正上方：标题 → meta → 按钮一行（开始游戏、设置、收藏），按钮底边距选中卡盒顶 28 px；不再把按钮放右侧。选中卡盒的分组标签隐藏（meta 里已有“昨天”等）。
> - 叠放：上/下翻牌；在牌堆上按左进入按钮（先落到最右边的收藏，再往左是设置、开始游戏）；按钮上按右（在收藏时）或上/下回到牌堆。焦点在按钮间移动时信息区和按钮位置绝对不能动（实机上会往左上偏移，是 bug）。
> - 分类页网格改 5 列（每格约 320x480），间距 48/32。

## 1. 页面结构

顶部标签：`首页`（不带数量） / `全部 N` / `Steam N` / `本地 N`。LB/RB 切换标签，点击标签也可以切。

- 首页：所有游戏按最近游玩排序，有两种样式可选。
- 全部 / Steam / 本地：分类页，结构都一样，只是筛选不同。
- Y 键保持现有行为（选中游戏时打开 游戏设置），不要改。
- 首页行尾有一个“全部 N”卡盒（网格图标加数量），按 A 跳到 全部 标签。
- 分类页按 B 回首页。

样式设置：设置 > 游戏库 > 首页样式，选项为 `展架` / `叠放`，默认 展架。按 A 立即生效，走切换动画和 toast，不需要保存按钮。

## 2. 首页 · 展架

参考 Selene（Playnite 全屏主题，MIT）：底部一排封面，选中的那个放大。

- **背景**：当前游戏的横幅图铺满全屏，切换时交叉淡入 400 ms，焦点位置取 focal x。
  - 左侧遮罩：`rgba(15,15,16,.86)` 在 0%，`.4` 在 42%，到 68% 变透明。
  - 纵向遮罩：顶部 0–18% 压暗 .55；底部从 46% 起逐渐压暗，到 100% 为 `#0F0F10`。
- **信息区**：左 96，右 96，底边在 y = 1200 − 596。
  - 左侧：标题 64 px / 600 字重，单行省略；标题下面是 meta，20 px，60% 白，内容为 `上次 · 已玩 X 小时 · 开发商 · 年份`。
  - 右侧：药丸按钮，高 64：白色主按钮 `开始游戏`，加两个圆形图标按钮（游戏设置、收藏）。
- **卡盒排**：底边距 64。
  - 普通卡盒 228x342，间距 28；选中卡盒 308x462。
  - 选中卡盒：上移 8，加 3 px 白描边，阴影 `0 26 50 -8 rgba(0,0,0,.7)`，再加一圈游戏主色光晕 `0 18 60 -10 主色`。
  - 未选中卡盒亮度降到 .78。
  - 整排平移，让选中卡盒的左边停在 x = 96 + (228+28)，也就是前面始终露出一盒；到首尾时夹住，不越界。
  - 分组标签（今天 / 昨天 / 本周 / 本月 / 年份 / 未玩过）写在每组第一盒上方 36 px 处，15 px，60% 白；选中时上移到 44 px。
- **动画**：宽高和整排平移都用 550 ms quart-out（cubic-bezier(.165,.84,.44,1)），新选中的卡盒扫过一道高光（1 s）。动画中途可以被打断。

## 3. 首页 · 叠放

移植自 CollectionViewPagingLayout 的 StackTransformView，用 "perspective" 预设，参数按下面调过。MIT，Copyright (c) 2019 Amir Khorsandi。

- 卡片 420x630，最上面一张的左上角在 (920, 300)，信息区放在左侧，垂直居中。
- 设 p = 卡片序号 − 当前序号：
  - scale = max(.2, 1 − max(p,0)·.08)
  - stackProgress = clamp(p/6, 0, 1)
  - pp = easeOut(stackProgress)·.15，其中 easeOut(x) = 1 − (1−x)²
  - tx = W·.2·max(p,0)
  - xAdj = −(((scale−1)·W)/2 + pp·W)
  - p < 0（已经翻过去的卡）：xAdj += 1.45·W·|p|，yAdj = .3·H·|p|，旋转 −|p|·π/10，透明度 0。p 夹在 −1 以下。
  - p ≥ 5 时淡出；p > 6 时隐藏。
- 我们自己加的：
  - 后面的卡按每层 .11 叠加黑色压暗，最多 .55。
  - 每张卡交替倾斜 ±0.035 rad，看起来像随手叠的一摞。
- 动画：transform 和透明度 600 ms quart-out。往后翻时，最上面那张向左下甩出去。
- 背景和信息区同展架。

## 4. 分类页（全部 / Steam / 本地）

背景是当前焦点游戏的横幅图，模糊 36 px，透明度 .4，切换时交叉淡入；向下渐变到 `#0F0F10`。页面整体纵向滚动。

### 4.1 最近（30 天内玩过的，最多 8 个）：散放的卡带

最近玩过的游戏已经从盒子里拿出来了，所以这一排画成单独的卡带。

- 尺寸 400x300，间距 24，横向滚动。
- 卡带外壳：
  - 深色渐变 `#34343a → #232327 (60%) → #1d1d21`。
  - 右上角切角：clip-path `0 0, 88% 0, 100% 9%, 100% 100%, 0 100%`。
  - 内高光：`inset 0 1px 0 rgba(255,255,255,.18)`，再叠一层 120° 斜向光泽。
- 卡带上的部件：
  - 顶部防滑纹：左 20，右 72，上 12，高 16，用 2 px 竖线每 9 px 一条。
  - 标签贴纸：左右各 16，上 38，高 186，圆角 6，贴游戏横幅图（按 focal x 对齐），加 115° 光泽。
  - 主色条：左 16，宽 120，上 236，高 6。
  - 金手指底座：左右各 40，贴底，高 30，颜色 `#141416`；里面是金色触点条，`#e0bf55` / `#8a6d1c` 交替，周期 10 px。
- 选中：上移 10，旋转 −1.2°，内描边 3 px 白，加投影和主色光晕。
- 卡带下面写标题（17 px / 600）和 `上次 · 已玩`（15 px，60% 白）。

### 4.2 全部 N：合上的卡盒，7 列网格

- 每格 2:3，用卡盒质感（见第 5 节），间距 44 / 28，左右边距 96。
- 选中：上移 8，加主色光晕，扫一道高光。
- 格子下面写标题和 `上次 · 已玩`；没玩过的写开发商和年份。
- 焦点移动规则：
  - 在最近一排按下，落到网格里最近的一列。
  - 在网格第一行按上，回到最近一排。
  - 左右移动不跨行。
- 焦点移动时页面自动滚动，让焦点保持在可见区域中部。

## 5. 卡盒质感

移植自 Finally 3D Game Cases，BSD-3，Copyright (c) 2026 SANSO。封面上叠以下几层：

1. 顶部主色条，高 4.6%，下面接 1 px 暗线。
2. 112° 斜向光泽：0% 处 .32，15% 处 .08，32–60% 透明，72% 处有一道细高光。
3. 左侧书脊折痕：3.2–3.9% 一道亮线，3.9–5% 一道暗线。
4. 左缘阴影：0% 处 .42，1.5% 处亮一点，到 7.5% 变透明。
5. 内描边：1 px 白 .22、3 px 黑 .18、4 px 白 .08。

## 6. 启动动画：插卡（三种页面共用）

移植 SANSO 的 runInsert（掌机变体：卡槽在屏幕底边），总时长 2200 ms：

- 卡盒从原位飞到屏幕中心，有轻微回弹。中心卡盒的高 ch = min(H·.56, W·.42·1.5)。
- 整个舞台转到 rotateX 8°、rotateY −22°。
- 盖子沿书脊打开，380 → 1040 ms 内转到 −160°，中间有一点回弹。
- 卡带从托槽里抬起并晃一下（880–1080 ms），沿弧线飞向屏幕底边的卡槽，1580 ms 插入。
- 插入时：卡槽发光，扫过一道亮光，整屏轻微震一下。
- 盖子在 1520–1830 ms 合上，卡盒飞回原位（1640–1990 ms）。
- 1700 ms 起淡入我们的启动画面：横幅图、标题、`正在启动`、进度条。

卡带用浅灰外壳，标签是角色图，下面是金手指。动画结束后正常启动游戏。启动失败或取消时，把整段倒放（退卡）。

音效：Web Audio 版本是在固定时间点合成的咔哒、闷响和滑动声。用 C# 实现时可以用短 wav 或合成音，加一个开关，默认开。

## 7. 每个页面都要有动画

所有动画都要能中途打断，进出对称，不能闪、不能跳尺寸、不能裁切或拉伸。验收用真实速度的录屏。

- **切换标签**：内容沿切换方向水平滑动 40 px，同时淡入淡出，220 ms，下划线跟着滑过去。
- **进入首页 · 展架**：横幅图从 1.04 缩放到 1 并淡入；卡盒排从下方 40 px 升起，每盒错开 30 ms。
- **进入首页 · 叠放**：卡片从右侧依次落到牌堆上，每张错开 40 ms。
- **进入分类页**：最近一排的卡带从下方 24 px 依次升起，每张错开 40 ms；网格整体淡入并上移 16 px。
- **切换首页样式**：两种布局交叉淡入淡出，同时把当前游戏的卡盒补间到新位置。
- **启动 / 退卡**：见第 6 节。

## 8. 输入

- 手柄：方向键和左摇杆移动焦点，按住时首次 360 ms 后开始连发，之后每 120 ms 一次。A 确认，B 返回，Y 打开游戏设置，LB/RB 切换标签。
- 键盘：同手柄。
- 触摸：
  - 点一下选中，再点一下启动。
  - 首页展架和分类页横排可以横向拖动翻页，叠放可以纵向或横向拖动。
  - 分类页可以纵向滚动。
