## 2. 功耗（核心，必须能自定义）

| 项 | CT | 我们 | 可调到什么程度 |
|---|---|---|---|
| 接管开关 | — | 有 | 开 / 关（关 = 完全交还系统，恢复原始值） |
| 模式 | 档位 + 滑条 | 智能 / 自动（插电 / 电池两套）/ 手动 | 智能 / 预设 / 手动 三选一 |
| 智能模式：目标帧率 | 无（CT 没有按帧率自动调功耗） | 有：关 / 30 / 40 / 45 / 60 / 90 / 120 | 预设档 + 自定义值 |
| 智能模式：功耗范围 | — | 有：下限 8–20 W，插电上限、电池上限（下限–35 W） | 三个滑条，1 W 一档 |

## 8. 显卡（Intel）—— 建议放「显示与声音」页，不放性能页

CT 把这些放在性能页里：
- XeSS 帧生成、Arc Sync（可变刷新率）、低延迟（Anti-Lag）、垂直同步方式。
- GPU 缩放 / 复古缩放、色彩（饱和度、对比度、锐化）。
- 分辨率、刷新率。

它们更像「画面」：建议放「显示与声音」页。性能页只在读数里显示 GPU 温度和占用。

## 主页面建议放这些（其余都进二级）

1. 读数：帧率、功耗、CPU 温度、风扇。
2. 作用范围：全局 / 当前游戏，插电 / 电池。
3. 功耗模式（智能 / 预设 / 手动），以及当前模式下最关键的一个值：智能 → 目标帧率，预设 → 选哪档，手动 → 瓦数。
4. 帧率限制。
5. CPU 最高频率。
6. 风扇模式，以及曲线入口。
7. 性能浮层档位。

## 已定（2026-10-15）

- 第 4、5 节的 CPU 细项全部做：Boost 模式、P / E 核分开的最高频率与 EPP、最大 / 最小处理器状态、核心驻留、Windows 电源模式，以及原有的 E 核调度。
- 按游戏配置第一版就做。
- 第 8 节显卡相关的放「显示与声音」页；性能页只在读数里显示 GPU 温度和占用。
