# 小黄鸭接入与 Magpie 预设编辑

2026-10-23。游戏库 0.1.84.0；后台沿用 0.17.58，更新对应设置模块。

## 小黄鸭

- 设置 → 小黄鸭自动识别本机程序：用户选过的路径、运行中程序路径、开机启动项、Steam 安装清单；不访问账户或验证购买记录。Steam 清单覆盖其他磁盘、自定义安装目录。
- 未找到时只显示重新检测和选择 LosslessScaling.exe。识别成功后隐藏这些接入控件，以一行显示“已识别 · 后台运行中 / 未运行”，定期核对程序是否仍在本机。程序校验绝对路径、文件名和 PE 文件头。
- 页面直接编辑本机 3.2.2 的原生配置：40 个档案参数，覆盖缩放算法及锐化、LSFG 3.1 固定 / 自适应、LSFG 2.3、光流与性能、捕获与队列、同步与延迟、HDR / G-Sync / 帧率、光标、显卡 / 显示器、裁剪、自动缩放；另有快捷键、自启、管理员启动、托盘、语言及主题 7 项应用设置。条件参数随算法、帧生成方式等展开。未知版本的现有枚举值保留，未经修改不重写为默认值。
- 默认和游戏独立档案可切换、修改；可复制当前档案给新游戏，编辑名称 / 匹配路径，删除自建档案。游戏页面的开关只改变 AutoScale，保留该游戏已有的缩放 / 补帧参数。缺少 Settings.xml 时可在本页直接初始化，无需打开原版。
- 使用现有设置页行、分组、选择器、触控加减、精确数值输入和恢复默认交互。修改暂存草稿，点击“保存并应用”同步；读取失败和保存冲突保留草稿。“重新读取”丢弃草稿需二次确认。底部提供后台启停和打开原版的辅助入口。
- 读取不启动小黄鸭或写配置。保存前检查整文件修订，写入前再次检查，防止覆盖原版刚保存的修改；保留未知 XML 节点、命名空间及其他档案，保存原文件到 data/lossless-backups，并原子替换。自启项与 XML 失败时回滚。
- 本机原版没有配置重载接口，退出时会将内存配置写回。因此运行中应用设置时，通过现有提权助手核对进程路径后短暂停止、写入，再最小化恢复；原来未运行则只保存。重启失败明确提示设置已保存但后台未恢复。不分发、复制或下载小黄鸭本体。

## Magpie

- 设置 → Magpie：预设选择、编辑、复制、新建、重命名、删除；内置预设可修改和恢复原始设置。
- 效果器从随包目录提供的 134 个 Magpie 效果中分类选择。每条效果链最多 12 项，可增删、上移/下移，编辑原生数值参数及倍数/适应屏幕/指定尺寸/充满屏幕。
- 数值行复用现有设置样式和交互：左右调整、触控加减、精确输入、Y 恢复默认。未保存草稿离开时两次返回确认；切换分类保留草稿，关闭设置结束编辑。
- 自定义配置持久化到 magpie-presets.json；原始目录不变。按游戏选用自定义预设后，修改和改名同步更新引用它的已启用游戏档案及元数据。删除自定义预设时引用回到“无”；恢复内置预设时引用回到原效果链。
- 保存供下次缩放使用，不中途重新配置正在运行的游戏画面。工具箱设置备份覆盖预设、小黄鸭关联和 Magpie 游戏元数据。
