Game Bar 快捷面板 · 第七版（参考图布局）

按你发的参考图：左侧一列只放图标的页签，右侧是平铺的列表，分组标题带图标，行与行之间用细线分隔，选项用圆角按钮，滑块上方是名称和数值。快设页保留现在 0.4.70 的布局。7 张图对应 7 页，都可以点。

每页放什么

  • 快设：照搬现在的功耗卡 + 8 个快捷键 + 九宫格；原来左侧竖栏的亮度、音量挪到掌机页
  • 性能：功耗与读数、模式、功耗上限、限帧、刷新率、风扇、性能显示、CPU
  • 掌机：亮度、音量；飞行模式、蓝牙、Wi-Fi、静音、熄屏下载、夜间模式、节电模式；震动；手柄模式
  • Magpie / 小黄鸭：缩放开关 + 分组参数，两列排，一屏放下
  • Windows：常用系统页一键跳转；电源：睡眠、锁定、注销、重启、关机

操作

  • 十字键 / 摇杆移动焦点；焦点在页签上即切页，按右进入页面
  • 开关和圆角选项按 A 立即生效；带 › 的行按 A 弹出选项列表
  • 焦点是左侧一条蓝色短标

说明

  • 黄点：原版 Magpie 有、我们的 Magpie 引擎还要补接口的项
  • 退出游戏、注销、重启、关机按两次确认
