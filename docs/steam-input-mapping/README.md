# Steam 输入的手柄映射：功能点和界面（调研）

2026-10-16，本机 Steam 大屏幕模式实看（经 Steam 自带的 CEF 调试口截图、读界面文字）。
为了能进配置器，临时把「艾尔登法环」的 Steam 输入先决替代从「使用默认设置」改成「启用」，看完已改回「使用默认设置」；

## 功能点

### 每个输入能绑的指令（第 3 层的页签）
- **手柄**：A B X Y、LB RB LT RT、选择 / 开始、十字键四向、左右摇杆四向和按下（其实还有 Xbox 键、背键等，随手柄而定）
- **鼠标**：左 / 中 / 右键、前进 / 后退键、滚轮上 / 下、移动至指定位置、按像素量移动
- **键盘**：整块键盘（Esc、F1–F12、数字行、字母、符号、Tab / Caps / Shift / Ctrl / Win / Alt / 空格 / Backspace / Enter）
- **数字键盘**：Insert Home PgUp Delete End PgDn、方向键、媒体键（Play Stop Next Prev）、Num Lock、小键盘 0–9 . / * - +
- **操作集**：更改操作集、增加 / 移除 / 按住操作集层（要布局里有多个操作集）
- **系统**：截图、切换手动录制、添加时间轴标记、创建剪辑、显示键盘、切换放大器、强制游戏关闭、更改玩家位置、触摸屏（原生 / 左键 / 右键 / 滚轮 / 光标移动 / 关闭）、音量加 / 减
- **视角**：重置视角、转动视角 360°、朝着输入方向（配合陀螺仪转鼠标、快速转向摇杆）

### 触发方式（一个键可以叠多个，每个各绑一个指令）
普通按压、**双击**、**长按**、开始按压、释放按压、**组合键**（按住另一个键时才触发）。

每种触发方式的设置：**按住以重复（连发）**、触感强度（关 / 低 / 中 / 高）、触发启动延迟 ms、触发结束延迟 ms、
**指令循环**（每按一次换下一个子指令）、**切换**（按一下开、再按一下关）、可中断、反转输入；另有添加子指令（一次按下发多个指令）、移除、重命名。

### 每组输入的「行为」（这组当什么用）
- 正面按键 / 十字键：按键板、十字键、摇杆、径向菜单、热键栏菜单、模式切换
- **摇杆**：无、摇杆、**摇杆鼠标**、快速转向摇杆、鼠标区域、十字键、**滚轮**、径向菜单、触摸菜单、热键栏菜单、模式切换；
  另有「点击」（按下摇杆）和「外环指令」（推到边缘时的指令）
- **扳机**：扳机键、模式切换；有「全扣」「轻扣」两个指令，「模拟输出扳机键」开关
- 陀螺仪（本机的手柄当 Xbox 手柄认，没有陀螺仪页）

### 行为的设置（摇杆为例）
灵敏度：水平 / 垂直比例、反转水平 / 垂直轴、**响应曲线**（线性等）；输出：输出到左 / 右摇杆、只输出一个轴、旋转输出角度；
死区：死区来源 / 形状；外环：指令半径、指令反转；触感强度。
扳机：临界值样式（微力扳机等）、**轻扣临界值**、按住连发、模拟输出。

### 布局层面
多套布局（官方 / 社区 / 自己的）可切换、导出；**操作集**（整套切换，比如步行 / 驾驶）和**操作集层**（叠在上面，按住才生效）；虚拟菜单（径向 / 触摸 / 热键栏）。

## 对我们意味着什么

Steam 的这些全是**软件层**做的：它读真手柄，再通过虚拟手柄 / 模拟键鼠把结果发给游戏。
手柄固件只能做「一个键 → 最多 5 个键码（可连发、可宏）」，长按 / 双击 / 切换 / 组合键 / 摇杆当鼠标 / 径向菜单 / 操作集都做不到。

所以要一比一还原，需要我们自己的输入层：
1. 用 HidHide 把真手柄藏起来，只让我们的后台读；
2. 用 ViGEm 建一个虚拟 Xbox 手柄给游戏，键鼠用 SendInput；
3. 后台按「布局」把真输入翻译成虚拟输入（触发方式、行为、操作集都在这一层）。
本机已经装着 ViGEmBus 1.22、HidHide 1.5（ClawTweaks 用的就是这一套），技术上可行；代价是一直有一个后台线程高频读写手柄（延迟要压在 1–2 ms 内），
并且和 Steam 输入、ClawTweaks 的虚拟手柄会互相打架，需要「谁接管」的开关。

固件映射（背键 M1 / M2 等）仍然有用：不开软件层时它是最省电、零延迟的方案；可以作为「简单模式」保留。
