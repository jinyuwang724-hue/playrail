# 显示与声音：鼠标与触控输入

版本：游戏库 0.1.7，后台维持 0.17.17。

后续 0.1.9：按用户要求移除左上返回角标、恢复标题位置，将 HDR 与屏幕缩放移入「显示」；共享输入实现扩展到性能及手柄页，见 [设置页触控](settings-touch-input.md)。以下保留 0.1.7 的验证记录。

## 支持的操作

- 点按开关或选项，直接选择对应值。
- 亮度、音量和驱动提供的连续数值显示滑条，支持点击定位与横向拖动；数值按原有步长取整并限制范围。
- 分辨率、刷新率等较多档位显示左右箭头，支持点按调节。
- 右侧列表支持鼠标滚轮与纵向拖动，底部的屏幕缩放可完整滚入视野。
- 左上角返回箭头可点击或触摸；手柄和键盘保留原有操作。

## 手势处理

鼠标、触摸和笔共用 Pointer 事件路径。点按在释放时生效，移动超过 8 DIP 后锁定方向：滑条上的横向移动调值，纵向移动滚动列表。开始滚动后再横移不会改值，拖动选项文字也不会切换选项。

同一时间只接收一根手指。取消、丢失捕获和页面关闭均不触发点按；刷新不会在手指按下期间替换设置状态。绘制与命中使用相同坐标和滚动位置。

主要实现：

- `Engine/SettingsPointer.cs`：手势方向、指针归属、取整与边界。
- `Stage/WallStage.Settings.Pointer.cs`：命中、点选、滑条和滚动（0.1.9 起由三页共享）。
- `Stage/WallStage.Perf.cs`：沿用设置行样式，显示与声音页额外生成命中区域。

- 22 项回归检查通过：原有 7 项设置队列检查，加 15 项点按、方向锁定、第二根手指、取消、取整与边界检查。
- Debug 构建通过；Release MSIX 打包并安装 0.1.7.0，仍有既有的 AOT 警告。
- 安装版鼠标实测：点击亮度滑条 100 → 75，横向拖动 75 → 50，静音选项可直接点选；均独立读取后台确认。
- 从亮度滑条纵向拖动后列表滚动，亮度保持 50；滚轮可显示底部选项。
- 返回箭头可返回控制中心并重新进入；滚动后方向键可继续选择设置。
- 自动测试更改的亮度、音量、静音已还原。
- 2026-10-19 用户在实体触摸屏上实测确认：右侧列表上下滑动、横向拖动亮度或音量滑条均正常。
