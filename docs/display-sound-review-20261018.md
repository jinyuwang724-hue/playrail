# 显示与声音功能检查（2026-10-18）

结论：掌机的基础快捷设置已经覆盖，仍有交互和恢复机制需要完善。本次删除当前机型不可用的自动亮度入口，并修复不同设置相互取消、驱动不支持的帧同步选项仍被展示的问题。

## 当前机器与自动亮度

- Windows 识别机型：MSI Claw 8 EX AI+ CG3EM Launch Pack；Intel Arc B390，内屏 PN8007QB1-2。
- `Windows.Devices.Sensors.LightSensor.GetDefault()` 返回 null；当前设备枚举只有方向传感器与 HID 传感器集合，没有可用环境光传感器。
- 实时 `get_display_state` 返回 `unsupported: ["autoBrightness"]`，没有 `autoBrightness` 值。
- 因而当前系统不支持环境光自动亮度。游戏库 0.1.6 不再展示该入口；后台能力判断保留，其他确实提供该能力的设备仍可显示。

## 本次修复

1. 自动亮度：本机不支持时直接隐藏，删除无作用的灰色占位行。
2. 设置写入：旧实现用同一个计数器合并所有设置，修改另一行可能取消上一行。改为同项合并、不同项保留，按操作先后顺序写入。不同 GPU 选项也分别保留。
3. 状态回读：写入完成后统一回读；旧的读取结果不会覆盖新修改。硬件不支持的错误不再误报为后台尚未接入。
4. 帧同步：旧实现直接列出 API 的全部六个模式。本机能力位为 `0x2d`，支持应用决定、垂直同步、平滑同步、限制到刷新率；不支持关闭垂直同步和极速帧。后台现在按真实驱动能力过滤，并阻止无效写入。

帧同步能力结构和接口依据 [Intel IGCL 官方接口定义](https://github.com/intel/drivers.gpu.control-library/blob/master/include/igcl_api.h)。

验证：7 项设置写入队列回归检查、3 项原生驱动能力筛选检查通过；四种帧同步模式的真机读写通过。Debug 构建成功；Release MSIX 已打包并安装 0.1.6，仍有原有的 AOT 警告。

后台维持 0.17.17，只更新 ClawPower 显卡能力筛选逻辑，没有重新安装整套后台。替换前通过原有 shutdown 接口正常关闭后台，替换后按原路径重新启动。旧文件在 `%LOCALAPPDATA%\ClawToolbox\repair-backups\display-sound-20261018\ClawPower-0.17.17-before.exe`。

## 尚未完善的部分

1. **鼠标与触屏操作**：`CcClick` 在显示子页直接返回，滚轮也未路由到这页；当前应使用手柄或键盘上下选项、左右修改。应补点击命中和滚轮/拖动滚动。
2. **显示模式恢复**：分辨率、刷新率和缩放直接写入，没有“保留此更改”的倒计时回退；分辨率/缩放引发窗口尺寸变化时还会关闭控制中心。应补恢复流程并保留当前页面位置。
3. 麦克风目前只有静音，没有输入设备选择和增益；作为快捷设置够用，需要完整声音管理时再扩充。
