# Game Bar 小组件：UI 设计需求（第一版）

2026-10-13。给做设计的一方看：要放哪些内容、怎么操作、有哪些限制。界面风格和布局由设计方决定。功能范围见 `gamebar-widget-features.md` 的“第一版”。

## 1. 交付物

- 一份可以直接在浏览器打开的 **HTML/CSS 设计稿**（单文件即可），包含下面列出的每个页面和每种状态。
- 设计稿会被直接搬进组件：组件里用 WebView2 显示网页，所以请写成真实的 HTML/CSS，不要只出图片。
- 文字全部用简体中文。

## 2. 运行环境和尺寸

- 显示在 Xbox Game Bar 里，作为一个小组件窗口；Game Bar 自己负责窗口外框和标题栏，设计稿只画内容区。
- 默认尺寸 **560 × 1080**（宽 × 高，逻辑像素），可调范围宽 400–900、高 520–1080。内容区要能在 400 宽时不挤、900 宽时不空。
- 掌机屏幕 8 英寸 1920×1200，系统缩放较大；正文字号不小于 14px，可点区域高度不小于 48px。

## 3. 操作方式（最重要）

- **主要用手柄操作**：方向键/左摇杆移动焦点，A 确认，B 返回上一页，LB/RB 可切换页面。也支持触屏点按。
- 每个可操作元素都要有**清楚的焦点样式**（选中时一眼能看出来）。
- 焦点移动顺序和视觉顺序一致，从上到下、从左到右；不要有焦点到不了的控件。
- 滑块：左右键调值；开关：A 切换；下拉：A 展开，方向键选，A 确认，B 取消。

## 4. 视觉风格

由设计方自由发挥，这里不做规定。唯一的硬性要求：内容浮在游戏画面上，在亮和暗的画面上都要看得清。

## 5. 页面和内容

### 首页
- 顶部一行：当前游戏名（没有游戏时显示“Claw 掌机工具箱”）和真实帧率。
- 读数一行（4 个）：功耗（W）、CPU 温度（°C）、帧率、电量（%，插电时有标识）。
- 快捷切换（4 个），每个按一下切到下一档，能看出当前在第几档：
  - 功耗：智能 / 各快捷瓦数（如 8、15、25 W）
  - 性能显示：关 / 1–4 档
  - 风扇：固件 / 静音 / 均衡 / 性能
  - 帧率限制：不限 / 30 / 40 / 60
- 进入各功能页的入口：性能与功耗、性能显示、风扇、震动、画面缩放、帧率与刷新率。

### 性能与功耗
- 状态行：来源（插电/电池；智能模式在游戏中显示游戏名和帧数）、上限 W、实际 W。
- 开关：接管功耗控制。关闭时页面只剩这个开关、“全部核心按 E 核调度”开关和“恢复原始功耗”按钮。
- 下拉：调节方式（智能 / 预设 / 手动）。
- 智能：目标帧率下拉（不限、30、40、45、60、90、120 帧）；滑块：插电上限、电池上限、最低功耗（5–35 W）；下拉：插电 CPU 频率、电池 CPU 频率（最高 4.7 GHz、1.5–4.5 GHz）。
- 预设：插电功耗、插电 CPU 频率、电池功耗、电池 CPU 频率。
- 手动：功耗、CPU 频率。
- 滑块：短时功耗加成（0–5 W）。
- 开关：全部核心按 E 核调度（改动后显示“重启后生效”）。
- 按钮：恢复原始功耗。

### 性能显示
- 开关：显示性能信息。
- 滑块：显示详细程度（1–4 档）。

### 风扇
- 状态行：转速、占空比、CPU 温度。
- 下拉：风扇模式（固件自动 / 静音 / 均衡 / 性能）。
- 非固件模式：6 个滑块（50/60/70/75/80/90 °C 各点的占空比，0–76%，性能模式可到 100%）；曲线改过时出现“恢复默认曲线”按钮；开关：风扇全速。
- 可选：用一条小曲线图直观显示这 6 个点（不要求可拖动）。

### 震动
- 滑块：震动强度（0–100%，步长 5）。
- 按钮：测试震动。

### 画面缩放（Magpie）
- 开关：画面缩放开/关。
- 下拉：游戏窗口（运行中的游戏列表）。
- 开关：等比铺满屏幕。
- 下拉：效果方案。
- 开关：追加锐化。
- 其余高级选项（捕获方式、处理帧率上限、3D 游戏模式等）收进一个“更多选项”子页面。

### 帧率与刷新率（新增）
- 下拉：帧率限制（不限、30、40、45、60、90、120）。
- 下拉：屏幕刷新率（按屏幕支持的列出，如 60 / 120 Hz）。

## 6. 需要画出的状态

- 正常：各页面的正常样子。
- 加载中：刚打开、数据还没回来。
- 后台未连接：工具箱后台没运行时，页面顶部一行提示，控件变灰。
- 未接管功耗：性能与功耗页只剩开关的样子。
- 体感助手冲突：一行提示“体感助手也在设置功耗，两边会互相改写”。
- 焦点：至少展示磁贴、列表项、滑块、开关、下拉各一个被选中的样子。
- 宽度：400 宽和 560 宽各一张首页。
