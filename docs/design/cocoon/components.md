# 组件库规范（Components）

本文档定义 Cocoon Design System 的标准组件目录，分为**基础控件（11 个）**、**数据可视化组件（4 个）**与**页面/容器模板（6 个）**三层。

所有组件遵循同一套**平台无关的数据契约**（Props / Events），不耦合任何业务状态或网络服务。尺寸默认采用参考画布（`1920 × 1200`）设计 px；跨端换算除以 `1.75` 即得 `dp`。

---

## 1. 统一列表数据契约（`CocoonRowItem`）

为解决早期实现中 `RowSheet`（`RsRow`）与 `CocoonPages`（`PerfRow`）两套模型分裂的问题，组件库对外暴露统一的声明式行模型：

```ts
type CocoonRowKind =
  | 'toggle'      // 拨动开关
  | 'dropdown'    // 单选 / 多选原地展开下拉
  | 'slider'      // 双层线性滑块（数值 − 轨道 +）
  | 'stepper'     // 灰胶囊步进器（− 值 +）
  | 'nav'         // 带 ▸ 的跳转或动作行
  | 'field'       // 两行元数据字段（标签 + 值 + 编辑图标）
  | 'order'       // 来源优先级排序行（↓↑ 展开为双十字键胶囊）
  | 'info';       // 只读信息展示行

interface CocoonRowItem {
  id: string;
  kind: CocoonRowKind;
  title: string;
  subtitle?: string;          // 标题下方灰色说明（26–27 px，单行省略）
  icon?: string;              // 左侧实心线面图标（可选）
  indent?: number;            // 子项缩进层级
  disabled?: boolean;         // 整行 40% 透明度，焦点仍可停靠但激活触发 Bump
  changed?: boolean;          // 非默认值标记：左侧画 6 px 紫色圆点（#7A4CFF）
  danger?: boolean;           // 危险语义：文字与图标切为 #F24B5A
  groupBreak?: boolean;       // 从该行起另起一张新的 Card3D 分组卡（间距 32–36 px）
  // 控件专属字段
  checked?: boolean;          // toggle
  options?: string[];         // dropdown
  selectedIndex?: number;     // dropdown (single)
  multiSelect?: boolean;      // dropdown (multi)
  checkedIndices?: number[];  // dropdown (multi)
  valueText?: string;         // slider / stepper / nav / field / info
  min?: number; max?: number; step?: number; value?: number; // slider / stepper
  canMoveUp?: boolean; canMoveDown?: boolean;                // order
}
```

## 2. 基础控件（Primitives & Controls）

### 2.1 `Card3D`（立体分组卡片）
- **用途**：承载同组设置行、左下实时读数卡、左侧栏选中分类卡。
- **结构**：6 层叠画（详见 [foundations.md §3.2](foundations.md#32-3d-立体容器卡card3d设置页读数卡选中分类卡)），圆角 `30 px`，组内行间用 **4 px 凹槽分隔线**（`2.5 px #E1E2E7` + `1.5 px #FFFFFF`），分组之间不放文字小标题，仅留 `36 px`（二级页 `32 px`）空白。
- **变体**：
  - `elevated`（默认，用于全屏页 `CpCard`）：竖向渐变 `#FDFDFE → #F0F1F4` + 双层投影。
  - `flat-group`（用于白色大面板 `ModalSheet` 内部）：实色 `#F7F8FA` + 单层 `5 px / blur 6` 投影 + `4 px #E2E3E5` 分隔线。

### 2.2 `CapsuleBadge`（顶部按键动作胶囊）
- **尺寸**：`134 × 74 px`，全圆角 `37 px`。
- **变体**：
  - **返回胶囊（`B ←`）**：底色 `#E2E3E7`，左侧 `Ø42` 圆圈 `#9A9CA3` 居中白字 `B`（Poppins Bold `22 px`），右侧 `#1E1E24` 圆头左箭头（线宽 `7 px`）。
  - **确认/开始胶囊（`Y ✓` / `Y ▶`）**：紫渐变 `#8A7BFF → #7A3CFF` + 紫色光晕投影（`#7A3CFF`，下移 `8 px`，模糊 `9 px`，`45%`），左侧 `Ø42` 淡紫圆 `#B9A9FF` 配 `#7A4CFF` 字母 `Y`，右侧白圆打勾或白色实心圆角三角。

### 2.3 `ToggleSwitch`（拨动开关）
- **尺寸**：轨道 `120 × 76 px`（圆角 `38 px`），圆钮 `Ø54`（`#FAFAFA`，投影下移 `3 px` / 模糊 `4 px` / `22%`）。
- **状态**：
  - **关**：底 `#E4E5E9`，内描边 `4 px #9A9CA3`，圆钮中心在左 `x + 38`。
  - **开**：对角蓝紫渐变 `#86A7FD → #8037FF`，无描边，圆钮中心在右 `x + 82`。
- **动效**：切换时圆钮 `150 ms`（`cubic-bezier(0.22, 1, 0.36, 1)`）滑动，紫底同步 `150 ms` 淡入/淡出；若开关控制下方子项显示，触发布局 `170 ms` 平滑展开/收起。

### 2.4 `InlineDropdown`（原地展开下拉选择器）
Cocoon 下拉**不是脱离文档流的悬浮弹窗**，而是让当前行在原地增高，把选项卡片直接嵌入行内、并将下方行推开：
- **触发胶囊（`PickPill`）**：宽 `400 px` × 高 `80 px`（侧栏紧凑版 `262 × 56 px`），全圆角，纯白 `#FFFFFF` 底、`1 px #ECEDF0` 描边、极淡投影（下移 `3 px` / 模糊 `6 px` / `14%`），右侧小三角（收起朝下 `#5F6168`，展开朝上 `#1E1E24`）。
- **展开选项卡（`OptionCard`）**：位于胶囊正下方 `14 px`，圆角 `min(30, optH * 0.4)`，底 `#FCFCFD`，`1 px #E6E7EA` 描边，投影下移 `5 px` / 模糊 `8 px` / `18%`；选项行高 `88 px`（紧凑版 `62 px`），项间缩进 `28 px` 画 `2 px #E6E7EA` 分隔线。
- **单选 vs 多选**：
  - 单选：当前生效项文字为亮蓝 `#4F9DF2`，按 `A` 选定并立即收起。
  - 多选：焦点行垫 `#ECE6FF` 淡紫底，右侧画 `Ø42` 勾选圈（已选为蓝紫渐变圆 + `2.5 px` 白环 + 白勾；未选为 `3.5 px #B4B6BC` 空心圆），按 `A` 切换勾选，按 `B` 收起。
- **焦点行为**：展开后，四角括号焦点框直接从整行弹簧缩放到当前聚焦的选项条上（目标圆角 `24 px`）。

### 2.5 `SliderRow`（双层线性滑块）
- **尺寸**：总行高 `160 px`（上层标题 `36 px` 距顶 `18 px`；下层控件中心距底 `44 px`）。
- **下层结构**：`当前数值（30 px 副墨色）` — `− 减号` — `10 px 高圆头轨道` — `+ 加号`。
  - 轨道底 `#DCDCE3`，已填充段横向渐变 `#86A7FD → #7340FF`。
  - 滑钮 `Ø48` 圆形（左上到右下渐变 `#9A9CFF → #6F3CFF` + 下移 `3 px` / 模糊 `5 px` / `30%` 投影）。
- **交互**：手柄聚焦该行时 `←/→` 直接调值（支持连发）；触控可直接拖轨道或点击左右 `−`/`+`（命中热区半径 `40 px`）。

### 2.6 `StepperPill`（步进灰胶囊）
- **用途**：少量离散档位或有序整数调整（不适合展开下拉的场景）。
- **结构**：右对齐灰胶囊（高 `76 px`，最小宽 `240 px`，按内容自适应 `textW + 160 px`，底 `#E6E7EC`），左右为 `#1E1E24` 粗线 `−` / `+`（线宽 `8 px`），中间居中 `30 px` 当前值。
- **交互**：手柄 `←/→` 步进，触控点击左半减、右半加。

### 2.7 `PowerMeterRow`（离散刻度条，紧凑侧栏专用）
- **用途**：快速调节离散数值范围（如 `5–35 W` 功耗刻度），视觉比普通滑块更具硬件仪表感。
- **结构**：行高 `138 px`，下方排布 `31` 根等距竖向刻度条（间距 `21 px`）。
- **特殊焦点规则**：聚焦到刻度条行时**隐藏常规四角括号**，改为将刻度条本身点亮为蓝紫渐变并放大当前值指示，避免括号与密集刻度打架。

### 2.8 `CircleTile`（圆形快捷开关）
- **尺寸**：直径 `120 px`，典型以 `2 × 5`（或 `2 × 4`）网格排布，横距 `22 px`、纵距 `18 px`。
- **状态**：关闭态浅冷灰 `#F5F6F9` + 深灰图标 `#2A2A31`；开启态竖向蓝紫渐变 `#8F8BFF → #7340FF` + 反白图标 `#FAFAFA`。
- **动效**：关闭层与开启层上下叠放，切换时仅对上层开启态做 `200 ms` 透明度交叉淡入淡出，零重绘开销。

### 2.9 `OrderRow`（优先级排序行）
- **未聚焦态**：右侧显示紧凑 `↓ ↑` 灰胶囊。
- **聚焦态展开**：焦点落在该行时，右侧胶囊以右端为锚点向左展开为 `258 × 84 px` 双按钮组（`150 ms`，`scaleX: 164/258 → 1`），内置两枚子胶囊 `✚↓`（左十字键高亮）与 `✚↑`（右十字键高亮）；到顶或到底时对应方向置灰 `#A8AAB0`。按下 `←/→` 时两行互相做 `170 ms` 换位滑动，焦点框跟随移动。

### 2.10 `InputCard`（模态文本/密码输入卡）
- **用途**：统一承载搜索词、元数据字段与 Wi-Fi 密码输入，避免系统原生输入框风格割裂。
- **特性**：白卡圆角容器 + 标题 + 原生输入法/触摸键盘托管；密码模式自动遮掩为圆点且不暴露明文切换按钮，支持提交错误提示并保留输入重输。

### 2.11 `ToastPill`（底部小胶囊提示）
- **位置与尺寸**：页面底部居中（距底 `30 px`），高 `84 px` 全圆角，宽度随文案自适应 `min(1500, textW + 130)`。
- **视觉**：白底浮层投影 + 左侧语义圆点图标 + `30 px` 墨色文字；上浮淡入，停留 `2400 ms` 后淡出。

## 3. 数据可视化组件（Data Visualization）

专为左下角实时读数卡设计，强调粗圆头、厚实易读、远距离掌机视角一目了然：

| 组件 | 视觉结构与核心参数 | 数据行为约定 |
| --- | --- | --- |
| **`GaugeRing`**（粗圆环仪表） | 开口朝下的 `270°` 圆弧（起始角 `135°`，扫角 `270°`），线宽 `24–28 px` 圆头；灰轨 `#E4E4EC`，进度弧左下到右上渐变 `#86A7FD → #8037FF`（静音/禁用态降灰 `#B4B6BE`）；圆心大号整数（`0.56r`，超 3 位缩为 `0.42r`）+ 下方单位（`0.22r`）+ 环外标题（`30 px`） | 数值须经平滑（如 5 秒滑动均值），`1 Hz` 更新，避免数字高频跳动 |
| **`ActivityBars`**（圆头柱状历史图） | 嵌在 `#F0F0F5`（圆角 `26 px`）内槽中；固定 `30` 根全圆头竖条（间距 `6 px`），空槽 `#E6E6EE`，填充柱竖向紫渐变，从左到右不透明度线性递增 `0.55 → 1.0`（最新一根最亮） | **固定时间分桶**（如每 2 秒固定一桶），历史 29 根柱子不重组不抖动，仅最右一柱实时更新 |
| **`CurveEditor`**（可编辑折线图） | `10 px` 粗圆头横向蓝紫渐变折线，节点为白心紫边圆（`r=12` / 边宽 `5`）；编辑选中点放大至 `r=18` 紫圆白心并在上方弹墨色圆角数值胶囊（`#1E1E24` 底 + `#FAFAFA` 字）；底部一颗 `r=9` 紫点标示当前实时位置 | `A` 进入编辑，`←/→` 选控制点，`↑/↓` 调值，`A/B` 写回退出 |
| **`MetricChip`**（状态读数胶囊） | 高度 `62 px` 全圆角，底 `#F0F0F5`，左 `25 px` 副墨色标签、右 `27 px` 主墨色读数（自动省略）；支持半宽（双列，间距 `14 px`）与全宽两种排布 | 缺数据时严格显示 `—`，不做虚假估算 |

## 4. 页面与容器模板（Page & Container Templates）

| 模板名 | 布局结构（1920×1200 基准） | 典型应用场景 |
| --- | --- | --- |
| **`TwoColumnPage`** | 顶栏（`B←` + `48 px` 标题）+ 左栏 `562 px`（顶部垂直分类导航 + 可选下方 `Card3D` 实时读数卡）+ 右栏 `1240 px`（可滚动分组 `Card3D` 列表，栏距 `30 px`）。左栏选中项各在原位交叉淡入淡出（`150 ms`），不滑移防错位。 | 系统设置、性能监控与调校、显示与声音组合页、设备信息页 |
| **`ModalSheetStack`** | 居中浮起白色大圆角面板（`1728 × 1060`，圆角 `64 px`，底 `#FAFAFA`），顶栏左 `B←` + 标题、右 `Y✓`/`Y▶`；支持多层压栈（Push/Pop）与分级入场动效；底部超出提示紫白描边向下箭头。 | 对象编辑、表单配置、多源刮削配置、向导流程 |
| **`SideDrawer`** | **左抽屉**（`672 px` 宽贴左满高，右两角圆角 `30 px`，均分全高导航行，焦点允许溢出右缘）；**右抽屉**（右上状态胶囊原位展开至 `768 px` 宽，含圆形开关网格 + 双滑块 + 分组卡片 + 内部子页切换）。 | 全局导航菜单 / 控制中心、游戏内/桌面快捷控制面板 |
| **`ContextMenu`** | 整屏组件层模糊 + 深灰遮罩；左半屏居中展示对象大图（`300 × 450`）与标题，右半屏 `622 px` 宽圆角白卡（圆角 `40 px`，行高 `117 px`，分隔线 `3 px`），末项支持危险红字二次确认。 | 卡片长按或按 `Y` 呼出的快捷上下文操作 |
| **`ConfirmDialog`** | 居中自适应高度圆角白卡（宽 `920 px`，圆角 `60 px`），顶栏 `B←` + 标题，中部单图或双图+紫色转换箭头，说明文案（`36 px`，行距 `1.3`），底部全宽绿色主确认按钮（高 `112 px`）与可选白色次按钮。 | 强制退出确认、多开切换确认、不可逆操作二次确认 |
| **`CoverRow` & `CoverGrid`** | **单行首页**：全屏清晰壁纸 + 顶部左右磨砂胶囊 + 底部单排 2:3 竖卡（`280 × 420`，步距 `330`，聚焦 `1.15×`）；**网格页**：模糊退后壁纸 + `6 列` 竖卡网格（`264 × 396`，横距 `52`，纵距 `48`）。 | 媒体库 / 游戏库首页、分类浏览墙 |
