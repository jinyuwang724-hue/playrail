# 动效物理与焦点引擎规范（Motion & Focus）

Cocoon 的交互质感有 50% 来自**可打断的临界阻尼弹簧**和**有生命力的四角括号焦点引擎**。本文档给出可直接照抄实现的数学公式与时间轴契约，适用于任何渲染后端（Composition / CSS / Web Animations / Compose / Flutter）。

---

## 1. 临界阻尼弹簧体系（Critically Damped Springs）

Cocoon 中除少数纯淡入淡出和惯性减速外，核心位移与展开均采用 **临界阻尼弹簧（`ζ = 1.0`，无过冲抖动、快速收尾、随时可打断）**。

### 1.1 物理参数表
| 语义预设 | 刚度 `k` (`stiffness`) | 阻尼比 `ζ` | 自然角频率 $\omega = \sqrt{k}$ | 约 95% 落定时间 | 适用场景 |
| --- | --- | --- | --- | --- | --- |
| `spring.focus` | `600` | `1.0` | `24.49 rad/s` | ~195 ms | 焦点框移动、尺寸缩放、圆环焦点滑动 |
| `spring.rowScroll` | `1500` | `1.0` | `38.73 rad/s` | ~125 ms | 封面行滚动、封面卡放大（`1.0 ↔ 1.15`）、网格滚动 |
| `spring.navSelected` | `1500` | `1.0` | `38.73 rad/s` | ~125–150 ms | 左侧栏分类选中态交叉淡入淡出 |
| `spring.drawerOpenX` | `4200` | `1.0` | `64.81 rad/s` | ~75 ms（前段 ~40 ms） | 右侧栏胶囊横向展开成面板宽 |
| `spring.drawerOpenY` | `1250` | `1.0` | `35.36 rad/s` | ~135 ms（延迟 `30 ms`） | 右侧栏纵向展开到满高 |
| `spring.drawerCloseY` | `2600` | `1.0` | `50.99 rad/s` | ~95 ms | 右侧栏先收起高度 |
| `spring.drawerCloseX` | `5200` | `1.0` | `72.11 rad/s` | ~65 ms（延迟 `50 ms`） | 右侧栏再收窄回胶囊 |

### 1.2 跨平台弹簧换算对照
不同框架对弹簧参数的定义不同，按以下公式可得到完全一致的运动曲线（以单位质量 $m = 1$）：
- **Android Jetpack Compose / React Spring / Framer Motion / SwiftUI**：直接传 `stiffness = k`、`damping = 2 * sqrt(k)`（即 `dampingRatio = 1.0`）。
- **WinUI / Windows Composition `SpringNaturalMotionAnimation`**：实测其 `Period` 满足 $\omega = 1 / \text{Period}$，因此 **`Period = TimeSpan.FromSeconds(1.0 / Math.Sqrt(k))`**，`DampingRatio = 1.0f`。
- **Web CSS（无原生弹簧时的近似）**：可用 `linear()` 采样生成临界阻尼曲线 $x(t) = 1 - (1 + \omega t)e^{-\omega t}$，或用 Framer Motion / Motion One / React Spring 驱动。

> **重要实现坑（打断瞬间跳转）**：在需要**瞬间归零**位置（例如切换设置分类时列表滚动归零）时，不能只赋值属性，必须显式取消正在运行的弹簧动画（在 Composition 中甚至需要用一段 `1 ms` 关键帧覆盖，防止残留弹簧帧回写旧位置）。

## 2. 四角括号焦点引擎（Concentric Bracket Cursor）

所有可聚焦的矩形目标（封面卡、列表行、胶囊按钮、下拉选项、分类项）均由**同一套焦点引擎**渲染，由 4 个视觉层叠加构成：

| 图层（从底到顶） | 视觉描述 | 关键参数 |
| --- | --- | --- |
| 1. `Glow`（紫色光晕） | 沿括号路径描 2 倍线宽 + 高斯模糊 | 色值 `#8037FF`，线宽 `2 × Sw`，高斯模糊 `σ = 3.5 dp` |
| 2. `Line`（流光主线） | 括号路径作遮罩，下方叠加旋转/沿周长流动的蓝紫渐变 | 线宽 `Sw = 4.8 dp`（`8 dp × 0.6`），圆头端点 |
| 3. `Rim`（白边光） | 沿主线内外各扩 `2 dp` 取差集环 | 色值 `#FAFAFA`，不透明度 `40%`（`alpha = 102/255`） |

### 2.1 同心几何公式（照抄即可像素对齐）
设目标矩形为 `(x, y, w, h)`，目标自身圆角为 `targetR`，当前密度换算为 `dp`（参考画布 `dp = 1.75`），粗细系数 `thick = 0.6`：

1. **外扩距离 `pad`（Outset）**：
   $$\text{pad} = \operatorname{clamp}(0.12 \cdot \min(w, h),\; 5\,\text{dp},\; 24\,\text{dp}) \times 0.6$$
   - 线中心框尺寸：$W = w + 2 \cdot \text{pad}$，$H = h + 2 \cdot \text{pad}$。
2. **同心圆角 `r`**：
   $$r = \text{targetR} + \frac{\text{pad}}{2}$$
3. **尺寸系数 `sf`、缺口 `gap` 与直腿长 `leg`**：
   $$\text{sf} = \operatorname{clamp}\!\left(\frac{\min(W, H)}{96\,\text{dp}},\; 0.35,\; 1.75\right)$$
   $$\text{gap} = \min(14\,\text{dp} \cdot \text{sf},\; 0.36 \cdot \min(W, H))$$
   $$r' = \min\!\left(r,\; \max\!\left(0,\; \frac{\min(W, H) - \text{gap}}{2}\right)\right)$$
   $$\text{leg} = \max\!\left(0,\; \min\!\left(18\,\text{dp} \cdot \text{sf},\; \frac{\min(W, H) - 2r' - \text{gap}}{2}\right)\right)$$
4. **纯圆形/胶囊目标退化规则**：
   - 当 `leg < 0.5` 时（例如圆形开关或很扁的胶囊），四个象限的四分之一圆弧两端各裁掉 $g = \min(9,\; \frac{\pi r'}{8})$，使四段括号之间自然留出呼吸缝。
   - **独立圆形图标（顶部页签按钮）**：使用固定「断开圆环」，半径 `36 px`，四段对称圆弧各占 **`52°`**（中心位于 `45° / 135° / 225° / 315°`），四个正方向缺口各占 **`38°`**。

### 2.2 全局统一流光（Perimeter Flow）
- **核心约束**：无论目标是大封面卡还是小下拉胶囊，流光转完一圈的绝对周期**全局统一为 `1800 ms`**（不按周长加速，避免小按钮闪烁刺眼）。
- **颜色混合曲线**：周长归一化坐标 $s \in [0, 1)$、相位 $\phi \in [0, 1)$ 处，颜色为 `lerp(#86A7FD, #8037FF, 0.5 + 0.5 * cos(2π(s - φ)))`。
- **宽矩形优化**：对宽高比悬殊的长条行（如 `1700 × 156`），不可直接绕中心旋转单张线性渐变（否则会变成左右整体闪色），而应拆为左右两半裁切，各用一条 3-stop 竖向渐变按周长坐标做 `24` 帧颜色动画（或直接用片元着色器 / SVG `stroke-dashoffset` / CSS `conic-gradient` 沿周长求值）。

### 2.3 焦点移动：弹簧 + 橡皮筋 + 尺寸变形
- **尺寸不变时**：位置走 `spring.focus`（`k = 600`），同时沿主移动方向叠加一段 **`230 ms` 的橡皮筋拉伸**：
  - 拉伸峰值系数：$k_{\text{peak}} = 1 + \min(0.45,\; \frac{d}{\text{axisSize}} \times 0.35)$
  - 关键帧：`t = 0` 为 `1.0` → `t = 0.3` 达峰值（缓动 `cubic-bezier(0.3, 0, 0.4, 1)`）→ `t = 1.0` 回到 `1.0`（缓动 `cubic-bezier(0.22, 1, 0.36, 1)`）。
- **尺寸变化时**（例如从整行跳入下拉选项）：按新尺寸重绘括号，位置从旧中心走 `spring.focus`，同时 `Scale` 从 `(oldW / newW, oldH / newH)` 弹簧弹回 `(1, 1)`，此时不叠加橡皮筋。

## 3. 核心场景动效编排（Choreography）

### 3.1 右侧快捷栏：胶囊变形双段展开
右侧栏不是凭空滑入，而是**右上角状态胶囊原地变身**：
- **展开**：
  1. `t = 0 ms`：左侧边界 `l` 以 `k = 4200` 横向拉宽到面板宽，同时底色透明度随横向进度 `clamp((l0 - l)/(l0 - l1), 0, 1)` 从灰磨砂平滑过渡到面板冷白渐变。
  2. `t = 30 ms`：高度 `h` 以 `k = 1250` 向下展开至满高；内容不做淡入，而是通过圆角矩形裁剪边界自然揭开，顶部状态行原地不动。
- **收起**（随时可打断）：
  1. `t = 0 ms`：焦点框 `60 ms` 淡出；高度 `h` 以 `k = 2600` 先收起。
  2. `t = 50 ms`：左侧边界 `l` 以 `k = 5200` 缩回原胶囊宽度。

### 3.2 左侧控制栏：贴边滑入 + 逐行错峰
- **打开**：遮罩 `200 ms` 淡入 + 背景组件层 `230 ms` 模糊至 `σ = 8`；面板从 `-W - 40` 滑入至 `0`（`200 ms`，`cubic-bezier(0.2, 0.8, 0.2, 1)`）；各导航行从 `t = 110 ms` 起每行间隔 **`55 ms`** 淡入并向右滑 `14 px`（`200 ms`）；最后一行到位后 `+40 ms`，焦点框以 `180 ms` 浮现（整体约 `0.6 s`）。
- **焦点框不进面板裁切**：焦点框置于面板裁切容器之外，允许括号和光晕自然溢出面板右侧边缘。

### 3.3 二级大面板（Modal Sheet）与游戏菜单（Context Menu）
- **游戏菜单（按 `Y`）**：封面从列表原位置起飞（上冲-横飞-落定至左半屏居中）→ 组件层模糊 + 深灰遮罩 → 右侧白卡从左上锚点弹出 → 焦点括号先在第一行左侧冒出一对小括号再向右展开至行尾。关闭时封面飞回原卡位。
- **二级大面板（`ModalSheet`）**：面板底从中心放大 → 骨架（顶栏胶囊 + 分组卡片）晚半拍放大 → 标题显现 → 列表行逐行间隔 **`33 ms`** 淡入放大 → 最后焦点框浮现。
- **动态重排（`Relayout`）**：开关展开/收起子项或排序行换位时，已有行和分组卡片用 `170 ms`（`cubic-bezier(0.22, 1, 0.36, 1)`）从旧 `Y` 滑至新 `Y`；卡片长高时用底边裁剪从旧高度展开；新出现的子项从上方 `-22 px` 处延迟 `30–50 ms` 淡入滑下。
- **开关切换**：圆钮 `150 ms`（`cubic-bezier(0.22, 1, 0.36, 1)`）滑至另一端，同时紫色渐变底 `150 ms` 淡入/淡出。

### 3.4 确认小窗（Confirm Dialog）与底部提示（Toast Pill）
- **确认小窗**：出现 `80 ms`（`scale 0.94 → 1.0` + 淡入），关闭近乎瞬时（1 帧），不拖泥带水。
- **底部提示胶囊**：底部居中上浮淡入，停留 **`2400 ms`** 后淡出。

## 4. 降低动态效果降级规则（Reduced Motion）

当系统或用户开启「降低动态效果（`prefers-reduced-motion: reduce` / `Reduced == true`）」时：
- 所有弹簧动画与位移动画**直接跳到终态**（`1 ms` 覆盖或直接赋值）；
- 取消橡皮筋拉伸、封面起飞轨迹和逐行错峰；
- 焦点框蓝紫流光停止旋转，锁定在静态相位（`-π/2`），保留清晰可见的静态蓝紫括号与白边光；
- 仅保留极短的语义显隐（≤ `1 ms` 或简单透明切换），确保无眩晕、零延迟。
