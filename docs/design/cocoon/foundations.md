# 基础视觉规范（Foundations）

本文档定义 Cocoon Design System 的坐标系、色彩语义、表面材质、排版字重、圆角法则与立体投影。全部数值与 [tokens.json](tokens.json) 严格一致。

---

## 1. 设计坐标系与 `dp` 换算

| 基准参数 | 数值 | 跨端换算方式 |
| --- | --- | --- |
| 参考画布 | `1920 × 1200`（16:10 掌机/桌面全屏逻辑单位） | 所有几何 Token 默认以参考画布 `px` 标注 |
| 密度换算比 | **`1 dp = 1.75` 设计 px** | 换算到 Android `dp`、Flutter 逻辑像素或标准 Web `px`（1080p/桌面 100% 缩放）时，将设计 px ÷ `1.75`（约 `0.57×`）或按视口短边等比缩放 |
| 光栅缩放比 | 渲染时乘以 `RasterScale`（例如 150% DPI） | 所有高斯模糊半径、阴影偏移与线宽均需随缩放比等比缩放，保证高分屏边缘锐利 |

## 2. 色彩系统（Color System）

Cocoon 采用**浅色中性陶瓷底 + 蓝紫流光强调色**的配色结构，信息对比清晰而不刺眼。

### 2.1 品牌与焦点强调色
| Token | 色值 | 用途 |
| --- | --- | --- |
| `brand.accentStart` | `#86A7FD` | 焦点流光、开关开启态、进度弧与滑块轨道渐变起点 |
| `brand.accentEnd` | `#8037FF` | 焦点流光、光晕基色、开关与进度弧渐变终点 |
| `brand.accentInk` | `#7A4CFF` | 左栏选中项图标与文字、已修改标记小圆点、操作胶囊字色 |
| `brand.accentDeep` | `#7340FF` | 滑块填充与快捷圆形开关开启态渐变终点 |
| `brand.accentSoftStart` | `#8F8BFF` | 快捷圆形开关开启态渐变起点 |
| `brand.pillActionStart / End` | `#8A7BFF → #7A3CFF` | 右上主动作胶囊（`Y ✓` / `Y ▶`）渐变面，配 `#7A3CFF` 45% 紫色投影 |
| `brand.selectionTint` | `#ECE6FF` | 多选下拉菜单中当前焦点行的淡紫底色 |

#### 2.1.1 动态渐变主题色与 OKLCH 感知派生规范
Cocoon 支持全局渐变主题色切换与自定义双色取色（`Stage/CocoonPalette.cs`），所有派生令牌均在 **OKLCH 感知均匀色彩空间**中由起止双色 `(Start, End)` 实时计算：
- **无灰阶流光插值**：周长流光括号与线性过渡按 OKLCH 最短色相弧插值，避免传统 sRGB 跨色相混合产生灰暗死区。
- **Bezold–Brücke 自然色相偏转**：预置渐变均采用高光端高明度（$L \approx 0.74\text{–}0.84$）向主体端浓郁明度（$L \approx 0.52\text{–}0.65$）过渡，并伴随 $20^\circ\text{–}45^\circ$ 邻近色相微旋，模拟真实釉面受光散射。
- **陶瓷表面可读性锁定**：派生墨色 `brand.accentInk` 自动锁定明度 $L \in [0.41, 0.53]$，保证在 `#FDFDFE` 立体白卡上的 WCAG 对比度恒大于 `4.2:1`。
- **8 套精选心理学渐变预设**：
  1. **星云蓝紫**（`#86A7FD → #8037FF`）：沉静专注 × 科技想象力（默认原生）
  2. **晴空冰蓝**（`#68D5FF → #2B6BFF`）：清透呼吸 × 零压清爽
  3. **青瓷薄荷**（`#68E3BE → #0D9E94`）：温润玉釉 × 自然舒缓
  4. **极光青紫**（`#56DFDF → #6650FF`）：冰青靛紫 × 灵动流光
  5. **暮光紫霞**（`#F08AE0 → #8E35F5`）：浪漫晚霞 × 华丽张力
  6. **朝霞珊瑚**（`#FF9BB3 → #EE4B7A`）：柔粉玫瑰 × 明快亲和
  7. **琥珀晨光**（`#FFBE64 → #F06735`）：暖金珊瑚 × 午后活力
  8. **曜石钛灰**（`#8C96AA → #2F3646`）：极简无彩 × 钛金工业质感

## 3. 四种核心表面材质（Surface Materials）

Cocoon 的视觉辨识度高度依赖表面材质的微层次，禁止用纯白 `#FFFFFF` 铺满整个画布。

### 3.1 全屏页底色（Page Canvas）
- 竖向冷灰渐变：`#EFEFF4`（顶）→ `#E2E3EA`（底）。
- 目的：让上面的 3D 立体卡片（`#FDFDFE → #F0F1F4`）有清晰的亮度抬升和底部阴影落点。

### 3.2 3D 立体容器卡（`Card3D`，设置页/读数卡/选中分类卡）
这是 Cocoon 最具代表性的容器，由 **6 层叠画**构成：
1. **底部重影（Drop Shadow）**：横向内缩 `4 px`、下移 `12 px`、高斯模糊 `14 px`、`rgba(0,0,0,0.20)`。
2. **贴身接触影（Contact Shadow）**：下移 `2 px`、高斯模糊 `3 px`、`rgba(0,0,0,0.10)`。
3. **面填充**：竖向渐变 `#FDFDFE`（0%）→ `#F0F1F4`（100%），圆角 `30 px`。
4. **底部内压暗**：卡片裁切内底部 `22 px` 高度，竖向渐变 `transparent` → `rgba(20, 20, 40, 0.063)`。
5. **顶部高光线**：距顶 `1.5 px`，横向留白 `0.6 × r`，`2 px` 纯白 `#FFFFFF` 高光线。
6. **外描边**：`1.5 px` 竖向渐变描边 `#F4F4F7`（顶）→ `#C4C5CC`（底），模拟顶光照射下的厚度倒角。

> **凹槽分隔线（Recessed Groove）**：`Card3D` 内部每两行之间不画单线，而是画 **2.5 px `#E1E2E7` 灰线 + 紧贴下方 1.5 px `#FFFFFF` 白线**（共 `4 px`），形成向下压出的物理凹槽感。

### 3.3 侧边抽屉底面（Drawer Surface）
左右侧栏采用多段柔和冷白渐变：
- `0% ~ 3%`：`#FAFAFA`
- `33% ~ 60%`：`#F6F7FA`
- `85% ~ 99%`：`#F2F6FA`
- `100%`（最底边 `10 px`）：`#E7EAF1`

### 3.4 模态遮罩与分层模糊（Modal Scrim & Layered Blur）
打开游戏菜单、二级页或确认弹窗时，背景遵循**「壁纸不糊、组件层轻糊、统一深灰压反差」**原则：
- **组件层模糊**：仅对首页的卡片、顶部面板、焦点框所在图层施加 `σ = 8 px` 高斯模糊；底层壁纸保持清晰不模糊。
- **遮罩层**：`rgba(35, 35, 37, 0.76)`（`#232325C2`）盖在壁纸和模糊组件层之上。实测等效像素变换 `out ≈ 0.24·in + 27`，能把暗部轻微抬起、压平整体对比度，避免纯黑遮罩发死。
- **左侧抽屉遮罩**：更轻一些，使用 `rgba(24, 24, 28, 0.55)`（`#18181C8C`）。

## 4. 排版与中英混排规范（Typography）

### 4.1 字体栈与字重黄金法则
| 字符集 | 首选字体 | 回退字体 | 常规/标题字重 | 说明 |
| --- | --- | --- | --- | --- |
| 拉丁字母、数字、符号 | **Poppins**（OFL 开源） | Segoe UI Variable Display / Inter | `600`（SemiBold）；徽章 `700`；大号数字 `800` | 几何圆形特征与 Cocoon 圆角体系高度匹配 |
| 中日韩字符（CJK，`U+2E80+`） | **PingFang SC Medium** | Microsoft YaHei UI / Noto Sans CJK SC | **强制封顶 `500`（Medium）** | **严禁对中文使用 `600`**：在 Win2D/DirectWrite 及多数渲染器上，没有真 SemiBold 字重的中文字体会触发合成加粗，在浅底上笔画糊成一团 |

### 4.2 字号层级（基于 `1920×1200` 设计 px，括号内为等效 `dp`）
| 角色 | 设计字号 | 等效 `dp` | 用途 |
| --- | --- | --- | --- |
| `pageTitle` | `48 px` | `27.4 dp` | 全屏页 / 二级页顶部大标题 |
| `fieldValue` | `40 px` | `22.9 dp` | 元数据编辑行的值文字 |
| `rowTitleSheet` / `navLabel` | `38 px` | `21.7 dp` | 二级页列表行名、左栏分类名 |
| `rowTitle` / `dialogBody` | `36 px` | `20.6 dp` | 设置页列表行名、弹窗正文（行高 `1.3`） |
| `rowValue` / `dropdownOption` | `32 px` | `18.3 dp` | 右侧值文字、下拉选项文字 |
| `toast` / `sliderValue` / `gaugeCaption` | `30 px` | `17.1 dp` | 底部提示胶囊、滑块读数、圆环下方标题 |
| `drawerTitle` | `28 px` | `16.0 dp` | 紧凑侧栏内行标题 |
| `chipValue` / `rowSub` | `26–27 px` | `15 dp` | 行下方灰色说明文字、胶囊读数 |
| `chipLabel` / `drawerPill` | `24–25 px` | `14 dp` | 胶囊标签、侧栏下拉胶囊内文字 |
| `keycap` | `22 px` | `12.6 dp` | 胶囊内圆形按键字母（`A` / `B` / `Y`） |

> **截断策略**：所有列表行标题、说明与选项文字均设为单行不换行（`NoWrap`）+ 字符级省略号（`Ellipsis`），并在右侧控件前保留固定安全间距，防止文字与控件重叠。

## 5. 圆角同心法则（Concentric Radius）

1. **大容器到小控件递减**：大弹窗/二级页 `64 px` → 确认小窗 `60 px` → 菜单卡 `40 px` → 抽屉/状态胶囊 `36 px` → 分组卡 `30 px` → 内部图表槽 `26 px` → 胶囊/开关/滑块 `height / 2`。
2. **封面卡比例圆角**：无论封面尺寸如何变化，圆角恒等于 `cardWidth × 0.17391305`（280 px 宽封面对应 `48.7 px`），保证视觉曲率一致。
3. **嵌套圆角同心**：当外框包住内目标（典型为四角括号焦点框包住卡片/行/胶囊）时，外框圆角必须满足 `R_outer = R_inner + outset / 2`（线中心同心），绝不套用固定死圆角。
