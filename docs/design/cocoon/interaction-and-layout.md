# 双模交互与响应式布局规范（Interaction & Layout）

Cocoon 的核心竞争力之一是**无需在「掌机模式」与「触屏/鼠标模式」之间手动切换**——同一套组件自动同时提供顶级的**手柄/键盘焦点体验**和**手机级直觉触控体验**。

---

## 1. 双模自动切换协议（Gamepad ↔ Touch Seamless Switch）

这是所有端实现必须遵守的交互状态机：

| 当前事件 | 状态迁移 | 焦点框（`CocoonCursor`）行为 | 自动滚屏行为 |
| --- | --- | --- | --- |
| 任意触摸按下 / 鼠标点击 | 进入 `TouchMode = true` | `80 ms` 淡出隐藏（手机/平板上不出现干扰视线的焦点框） | 设为 `ManualScroll = true`，停止自动把列表滚回焦点行 |
| 任意手柄方向键 / 确认 / 肩键 / 键盘方向键 | 切回 `TouchMode = false` | 标记为首次显形，直接在当前聚焦项处 `140 ms` 淡入出现（不从远处飞来） | 恢复 `ManualScroll = false`，若焦点行在视口外则弹簧滚入安全区 |

## 2. 手柄与键盘交互规范（Gamepad & Keyboard）

### 2.1 全局按键语义契约
| 逻辑动作 | 手柄映射（XInput） | 键盘映射 | 语义说明 |
| --- | --- | --- | --- |
| 导航移动 | 十字键 / 左摇杆 | `↑ ↓ ← →` | 项间移动、调滑块/步进、下拉内选选项 |
| 确认 / 激活 | `A` | `Enter` / `Space` | 切开关、展开/选定下拉、进入子页、从左栏进入右栏 |
| 返回 / 取消 | `B` | `Esc` / `Backspace` | 严格按层级退回：**展开下拉 → 右栏回左栏 → 子页栈弹出 → 关闭抽屉/页面** |
| 上下文 / 主动作 | `Y` | `Tab` / `Ctrl+S` | 卡片上呼出 `ContextMenu`；二级页中触发右上 `Y✓` 保存或 `Y▶` 开始 |
| 辅助动作 / 关闭运行 | `X` | `Delete` / `F2` | 正在运行卡片上弹出退出确认；设置项中恢复默认 |
| 页签切换 | `LB` / `RB` | `Q` / `E` | 顶栏页签或子页标签切换（抽屉/菜单打开时拦截，防止误切底层页面） |
| 左侧控制栏 | `View`（视图键） | `M` / `F1` | 呼出/收起左侧导航抽屉 |
| 右侧快捷栏 | `RT`（右扳机按下沿） | `F2` / 点击右上胶囊 | 呼出/收起右侧快捷面板（必须用按下沿防抖，避免半按反复触发） |

### 2.2 控件级方向键规则（防误操作约束）
- **普通选项行（`nav` / `toggle` / `dropdown`）**：**禁止**用 `←/→` 直接改值！`←/→` 留给双栏切换（在右栏按 `←` 退回左栏分类，在左栏按 `→` 进入右栏第一项）；改值统一按 `A` 切换开关或原地展开下拉。
- **滑块行（`slider`）与步进胶囊（`stepper` / `PowerMeter`）**：聚焦该行时允许 `←/→` 直接调值，并开启**差异化连发节拍**：
  - 连续滑块（亮度/音量）：连发间隔 **`75 ms`**
  - 离散刻度（功耗/步进）：连发间隔 **`110 ms`**
  - 普通列表导航：使用系统默认连发节奏，防止滚飞。
- **进入右栏焦点落点**：从左栏切入右栏时，焦点固定落在**当前分类的第一条可聚焦行**；切换左侧分类时，右栏滚动位置立即归零（取消残留弹簧）。
- **视口安全滚屏**：列表滚动保持聚焦行上下各留 **`60 px`** 安全余量；展开下拉时将整个选项卡片纳入安全区（底部多留 `80 px`）。

## 3. 触控与指针交互规范（Touch & Pointer）

### 3.1 列表滚动、惯性与越界回弹
- **拖动阈值**：垂直位移 `< 18 px` 视为点击，不触发滚动；超过 `18 px` 进入拖动并立即淡出按下高亮。
- **速度估算**：一阶指数平滑 `vel = vel * 0.4 + (dy / dt) * 0.6`（单位：设计 px/s）。
- **越界橡皮筋（Overscroll）**：超出 `[0, maxScroll]` 范围时，位移衰减为手指位移的 **`1/3`**。
- **松手惯性**：目标位置 `clamp(scroll - vel * 0.32, 0, maxScroll)`，时长 `clamp(|vel| * 0.5, 220, 650) ms`，缓动曲线 `cubic-bezier(0.15, 0.7, 0.25, 1.0)`。

### 3.2 直觉点击与局部手势
- **按下反馈（Press Highlight）**：手指落在列表行上时立刻叠加淡灰蒙层 `rgba(30, 30, 60, 0.07)`，抬手或转为拖动时 `160 ms` 淡出。
- **滑块直接拖动**：按在滑块轨道区域（轨道左右各扩 `30 px` 容错热区）直接锁定为滑块拖拽，阻止列表垂直滚动；点按 `−`/`+`（半径 `40 px` 热区）按步长单次增减。
- **点按直接生效**：点击开关直接翻转、点击下拉胶囊原地展开、点击下拉选项直接选中、点空白处收起下拉。
- **左缘返回让出**：触控起点落在屏幕最左侧边缘保护区（如 `x ≤ EdgeBackPx`）时，组件不拦截事件，交由系统/宿主处理「边缘右划返回」。

## 4. 声音反馈契约（Audio Cue Contract）

组件库不内置音频解码器，而是通过抽象回调 `onCue(cue, pan?, pitch?)` 向宿主报告语义事件，宿主可自由接入自定义音频引擎、系统音效或静默：

| 语义标识（`CocoonCue`） | 触发时机 | 附加参数 |
| --- | --- | --- |
| `Nav` | 焦点在项间移动、切换分类、步进调整 | `pan ∈ [-0.5, 0.5]`（声相跟随焦点横向位置） |
| `Positive` | 确认选定、开关打开、保存成功 | — |
| `MenuIn` / `MenuOut` | 打开/关闭抽屉、菜单、二级页或展开下拉 | — |
| `Back` | 返回上一层、收起下拉、取消操作 | — |
| `SliderUp` / `SliderDown` | 滑块数值增/减 | `pitch = 2^(frac - 0.5)`（音高随百分比线性升高） |
| `Bump` | 到达列表尽头、点击禁用项、不可操作反馈 | — |

## 5. 跨形态与响应式布局适配（Responsive Adaptation）

虽然参考规格诞生于 `1920 × 1200`（16:10 掌机全屏），但只需按「视口形态断点 + `dp` 等比缩放」即可复用到任意设备：

| 设备形态 | 典型视口 | `TwoColumnPage` 适配 | `SideDrawer` 适配 | `ModalSheetStack` 适配 | `CoverGrid` 列数 |
| --- | --- | --- | --- | --- | --- |
| **掌机 / 电视 / 10ft** | `1280×800` ~ `2560×1600`（按短边等比映射到 `1920×1200`） | 保持经典双栏 `562 : 1240`（约 `31% : 69%`），左下挂读数卡 | 左栏 `35%` 宽，右栏 `40%` 宽（右上胶囊原位变形） | 居中 `90% × 88%` 浮层大卡（圆角 `64 px`） | `6 列`（首页单行露 `5.5` 张） |
| **桌面窗口（Web / PC）** | 宽度 `≥ 1024 px`（自由缩放） | 左栏固定 `280–340 CSS px`，右栏弹性最大 `780–900 CSS px` 居中 | 固定 `360–420 CSS px` 宽浮层抽屉 | 最大宽 `960 CSS px`，上下留白 `40 px` | `auto-fill`（最小卡宽 `150 CSS px`，保持 `2:3` 与 `0.174×w` 圆角） |
| **平板竖屏** | `768–1023 px` | 窄左栏 `240 CSS px` + 右栏弹性；读数卡移至右栏顶部横向排布 | `360 CSS px` 宽抽屉 | 宽 `92%`，圆角收敛至 `28 CSS px` | `4 列` |
| **手机竖屏** | `< 768 px` | 拆分为两级路由（分类列表页 → 详情分组页），隐藏焦点框，默认纯触控模式 | 底部弹出 Sheet 或 `86%` 宽抽屉 | 全屏推入（顶部圆角 `24 CSS px`） | `3 列` |
