# 设置页触控与分组调整

游戏库 0.1.9，后台仍为 0.17.17。

## 显示与声音

- 删除 0.1.7 新增的左上返回箭头及其命中区域，标题恢复 x = 40 的原始位置。
- 删除「更多显示」分组；HDR、屏幕缩放和其他屏幕选项一起放入「显示」。左侧摘要同时显示屏幕缩放。
- 保留鼠标点选、亮度和音量滑条；B / Escape 返回。

## 性能

- 开关与模式可直接点选，连续数值可点击或横向拖动滑条，离散档位可点击左右箭头。
- 右栏支持纵向拖动和滚轮；拖动超过阈值后锁定方向，滑条位置的纵向拖动不会改值。
- 「编辑这档曲线」展开六个温度点的风量滑条及完成入口，遵守原有风扇上限。左栏仍只显示曲线和读数。
- 手柄原有的曲线选点和调节方式保留，结束编辑后焦点回到曲线入口。

## 手柄

- 左侧分类可直接点选；上下滑动或滚轮切换分类。
- 死区、外圈、扳机行程、震动强度有滑条，无需先按 A 进入编辑。滑条上的纵向滑动不改值、不切换分类。
- 点按映射键打开设置；指令页签和键格可点选，选择指令时可横向滑动换页。
- 按键页、触发设置页共用可滚动列表，内容限定在视口内，底部返回提示可点击。多触发列表底部的恢复入口可以正常滚入视野。
- 手柄数值调整采用原有延迟保存机制；摇杆和扳机改为按类别、左右两侧分别合并，避免连续操作另一侧时取消先前修改。写入全部结束后再回读，刷新不覆盖按下中的修改。
