# 紧凑档组件规范

2026-10-29 定，草案。用于快捷面板、Game Bar 小组件这类小空间。组件的形状、焦点方式和游戏库性能页、显示与声音页一致，只把尺寸和间距按比例缩小。文案遵守 [ui-copy-guidelines.md](ui-copy-guidelines.md)。

单位是逻辑像素。掌机 1920×1200、缩放 1.5，换成屏幕像素要 ×1.5（括号里是屏幕像素）。

## 骨架（参考 Steam 快速菜单的实测数值，见 artifacts/quick-settings-design/qam-measure.md）

| 项 | 值 | 为什么 |
| --- | --- | --- |
| 面板宽 | 400（600 px，屏宽 31%） | QAM 是 348（522 px）。中文标签加右侧文字选项（如「模拟全核心 E 核 … 关 开」）在 348 宽里放不下，400 刚好一行放下，又不超过 1/3 屏 |
| 图标栏 | 48 宽；图标位 32 圆，间距 12，竖向居中 | 同 QAM 的 48；圆形图标位沿用 OOBE 的圆节点 |
| 内容区 | 352；左 8、右 12 外边距，行内左右再 12 | |
| 底色 | 从当前游戏画面取主色，压到很暗的实色（绝区零是 #0D1716）；右边 1 px 6% 白边 | 不用 Steam 蓝灰，不做模糊渐变边 |
| 分区标题 | 22 / 700 SF Pro Display，高 56（上 16）；滚动时吸顶 | 同 QAM 的吸顶标题 |
| 分组名 | 12 / 500，42% 白，字距 0.04em，上 12、下 4 | 性能页的「功耗 / CPU / 风扇」 |

## 行

| 项 | 值 |
| --- | --- |
| 行高 | 40（60 px），带滑条的行 8 + 24 + 8 + 16 + 12 |
| 名字 | 15 / 500，行高 20，白 |
| 值 | 15 / 500，60% 白，等宽数字；跳转行末尾 14 的 › |
| 分隔线 | 不画，靠行高和分组名分组 |
| 焦点 | 整行变成白底墨字的胶囊：单行圆角 20（高的一半），带滑条的行圆角 16；行内的次要文字变成 50% 墨 |

## 控件

| 控件 | 值 |
| --- | --- |
| 文字选项（含「关 开」） | 15 / 500，间距 14；当前项白字加 2 px 下划线（低于字 5 px）；其余 60% 白。焦点行里当前项墨字墨线，其余 50% 墨 |
| 滑条 | 轨道 2 px 线，22% 白；填充白；把手 12 空心圆（2 px 白边，中间填面板底色），和性能页曲线的节点一样。焦点行里全部换成墨色 |
| 图标滑条（亮度、音量） | 18 的图标 + 滑条 + 右侧 24 宽数值，单行 40 高，不写名字 |
| 读数 | 数字 24 / 600 SF Pro Display，单位 12 / 500 60% 白，说明 11 / 500 42% 白；四列等分，间距 8 |
| 温度、功耗偏高 | 数字改成 #FF8A5C |
| 图标栏焦点 | 白圆墨图标，外加 3 px 18% 白光圈；当前分区 14% 白圆 |

## 待定

- 字号是否并入 type-system 的 8 级 token（目前 15 / 12 / 11 是紧凑档新增）。
- 底色取色算法：画面主色，明度压到 8～10%，饱和度不超过 30%。
