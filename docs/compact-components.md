# 紧凑档组件规范

2026-10-29 定，草案第三版。用于快捷面板、Game Bar 小组件这类小空间。组件的形态和焦点方式跟游戏库性能页、显示与声音页一致，只按比例缩小尺寸和间距。文案遵守 [ui-copy-guidelines.md](ui-copy-guidelines.md)。

单位是逻辑像素。掌机 1920×1200、缩放 1.5，换成屏幕像素要 ×1.5（括号里是屏幕像素）。

## 形状只有圆和胶囊

全页只用一种形状语言：圆（图标位、磁贴按钮、封面、滑条把手）和胶囊（行焦点、按钮、名字浮签、长磁贴，圆角 = 高的一半）。不出现方块、小圆角矩形，也不圆方混用。新组件先想能不能做成圆或胶囊。

## 首页（只放这四块）

1. **正在游戏**：88 圆形封面（游戏画面裁切）+ 游戏名 32 / 700；下面一排读数，数字 30 / 600，单位 14，说明 13。
2. **滑条**：「功耗」组下 PL1、PL2 两条（名字 + 数值 + 滑条），再加亮度、音量（图标 + 滑条 + 数值）。
3. **磁贴**：可编辑，三种方案待选（见下）。
4. **底部两项**：「返回游戏库」「退出游戏」两个 52 高胶囊按钮，退出游戏红字。

## 磁贴（三种方案，同一套颜色）

颜色跟随背景：开 = 从游戏画面取色后提亮（绝区零 #A9DFD3，墨色图标），关 = 13% 白半透明。不另加强调色。

| 方案 | 形状 | 尺寸 | 显示 |
| --- | --- | --- | --- |
| 1 圆形按钮 | 圆 | 60，5 列，行距 14 | 只有图标；名字在焦点时浮出 |
| 2 横胶囊 | 胶囊 | 两列，高 60；左侧 44 图标圆 | 图标 + 名字 + 状态两行 |
| 3 竖胶囊 | 竖胶囊 | 5 列，高 92，圆角 34 | 图标在上，状态在下 |

编辑：入口是最后一格铅笔图标（虚线描边）。编辑时磁贴轻微抖动，左上角 22 圆形 × 删除，可拖动排序。

## 焦点

| 控件 | 焦点样式 |
| --- | --- |
| 滑条 | 只亮把手：变成 24 实心白圆 + 两圈光晕（4 px 24% 白、10 px 8% 白）；行不加底色 |
| 文字选项 | 单个选项变白底墨字胶囊 + 光晕 |
| 跳转行 | 整行 9% 白浅底胶囊 |
| 磁贴 | 放大 1.06 + 3 px 白环；方案 1 名字在上方浮出 |
| 图标栏 | 白圆墨图标 + 光晕，名字在右侧浮出；当前分区 16% 白圆 |

## 电源

- 点电源（或按 A）：其他栏图标淡到 12%，电源选项从电源图标原位沿栏竖向依次滑上去（每个间隔 64，依次延迟 40 ms）：切换到桌面、睡眠、重启、关机。都是 56 圆，重启、关机图标红色。
- 焦点时名字在右侧浮出。
- 重启、关机二次确认就在原位：选中后按一次 A，这个圆变红底，浮签变红并写明后果（「再按一次关机 · 未保存的进度会丢失」）；再按一次 A 执行，按 B 收回。不弹面板。
