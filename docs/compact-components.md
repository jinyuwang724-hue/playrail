# 紧凑档组件规范

2026-10-29 定，草案第二版。用于快捷面板、Game Bar 小组件这类小空间。组件的形状和焦点方式和游戏库性能页、显示与声音页一致，只把尺寸和间距按比例缩小。文案遵守 [ui-copy-guidelines.md](ui-copy-guidelines.md)。

单位是逻辑像素。掌机 1920×1200、缩放 1.5，换成屏幕像素要 ×1.5（括号里是屏幕像素）。

## 为什么第二版把字和行放大

第一版正文 15（22 px）、行高 40（60 px），在 8 英寸屏上一臂远看偏小，同屏项目也太多。第二版正文 18（27 px）、行高 52（78 px），和游戏库性能页的正文接近，手柄和手指都更好点。每个分区只放 2～4 项，其余进下一层。

## 焦点（两级）

焦点尽量落在具体控件上，行只给一层浅底提示「焦点在这一行里」。

| 控件 | 焦点样式 |
| --- | --- |
| 行 | 9% 白浅底胶囊（圆角为行高一半） |
| 滑条 | 把手变成 22 实心白圆 + 两圈光晕（4 px 22% 白、10 px 7% 白）；行同时有浅底 |
| 文字选项 | 单个选项变成白底墨字胶囊 + 光晕，下划线隐藏 |
| 跳转行 | 整行浅底 |
| 磁贴 | 放大 1.06 + 3 px 白环；名字在上方浮出（白底墨字），平时不显示 |
| 图标栏 | 白圆墨图标 + 光晕；当前分区 16% 白圆 |
| 电源菜单 | 项目白底墨字；关机、重启是红字；选中关机后菜单换成确认：「关机？未保存的游戏进度会丢失」+ 取消 / 关机两个按钮，焦点默认落在关机（红底） |
