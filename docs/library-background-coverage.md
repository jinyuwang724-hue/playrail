# 游戏库封面下方背景覆盖修复

游戏库 0.1.10。

## 原因与修复

之前的 0.1.4 只针对胶片墙：隐藏了游戏库左右两半不透明底色，并让胶片墙绘制整屏。隐现、莫奈、漫游仍被底色遮住，而且只绘制侧边栏开口范围，背景视觉也随开口平移。

现在所有开启的背景统一使用整屏覆盖：隐藏左右底色、绘制完整视口、固定背景位置。背景动画也不再依赖侧边栏是否打开。关闭动态背景后仍恢复原来的静态底色；后台、控制中心自身的处理和各背景的参数保持原样。

## 安装版验证

在 0.1.10.0 上通过应用内设置逐项切换，并在每次退出全屏预览、重新显示游戏封面后观察卡片间隙：

- 隐现：混合、像素、流体。
- 莫奈。
- 漫游：纸张纹理、镜头畸变。
- 胶片封面墙。

七种效果均能显示在封面之间，未再被统一黑色底层遮挡。关闭 / 重新开启动态背景、往返控制中心也正常。

Release MSIX 构建并安装成功，保留既有 AOT 和符号包警告。检查期间日志未见背景绘制异常。

检查结束后背景配置与检查前逐行比对一致，当前恢复为隐现混合；其他背景的效果、胶片布局、数量、速度、角度和暗化值均保留。
