# 游戏模式窗口管理：前端常驻与窗口切换器（2026-11-03）

安装：游戏库 **0.1.201.0**（由 0.1.200 原位升级，偏好未变），ClawShell **1.0.2**，后台仍为 0.17.58。

## 做法

游戏模式 = 关掉 explorer，没有任务栏和桌面。所以由两层一起保证「总有游戏库窗口、它不会停在最小化」：

- **ClawShell 监视进程（watch / shell）**，每秒一次：游戏库进程不在就重新激活（带 `--game-shell`）；进程在但窗口不可见或最小化，就给窗口发 `game-shell` / `keep-game-shell` 消息让它显示（不抢前台）。60 秒内失败 3 次才退回桌面。
- **游戏库自己**（`MainWindow.GameShell.cs`，每 0.5 秒）：刚进游戏模式时拉到前台；窗口被最小化或隐藏就原样放回（停在前台窗口后面）；前台没有任何应用窗口（游戏关了、别的窗口都最小化了）1 秒后自己回到前台。游戏模式下关窗口、「退出游戏库」、最小化都改成停在游戏后面，不会真的关掉或进托盘。
- **窗口切换器**沿用 0.1.197 的：游戏模式下长按特殊键直接打开独立切换器（也在控制中心「窗口」页）。列表含最小化的窗口，A 切过去时先还原。

## 1.0.2 修的问题

0.1.200 的监视进程把「进程在、窗口还没出来」当成一次失败，并立刻再激活。游戏库崩溃重启、冷启动、切桌面时窗口都要几秒才出现，连续三次就会被误判成崩溃循环、退回桌面（11-02 01:17 切桌面时日志里就有一次误判）。开机时没在 3 秒内抢到前台也算失败。

现在：窗口未就绪先等 10 秒宽限，期间每秒继续请它显示；宽限过后才算失败。开机进程和窗口都在、只是没抢到前台，不再算失败，交给监视继续看着。外壳测试 42 + 14 项通过（新增 3 项）。

## 0.1.204：快设面板与切换器的五个问题（11-04）

1. **唤出快设时页面跳到控制中心**：日志里每次按快设，控制中心先被一个「菜单」打开，约 0.75 s 后快设才到（关面板那一下，菜单落在快设之后约 0.5 s）。现在快设到达时，若控制中心是 1.2 s 内被菜单打开的，直接撤掉（不走形变）；快设之后 1 s 内的菜单不开控制中心（日志 `control center undone` / `menu ignored`）。这个「菜单」从哪来还在用 `artifacts/game-shell-201/padlog` 记录器确认。
2. **再按快设关切换器时误开快设面板**：切换器开着或正在进场时，短按快设 = B，收起切换器（`quick key closed the window switcher`）。
3. **游戏库也是一个窗口**：切换器里多一张「游戏库」卡（大图标，没有 ×，X 键无效），选它回到墙，游戏库留在前台。
4. **唤出快设时游戏库和游戏窗口不变**：游戏模式下面板底下不再压暗，只多一块面板。
5. **面板开着时别的东西不能操作**：点击先交给面板（以前左上角触摸导航会先吃掉点击、打开控制中心），滚轮不再滚动下面的墙；面板外点一下 = 收起面板。

## 0.1.210 + ClawShell 1.0.3 + 后台：保留 explorer 的游戏模式（试验，11-04）

开关：设置 › 通用「游戏模式保留系统输入法（试验）」= `ClawShell set-covered on|off` = `shell\keep-explorer.flag`。开着时进入游戏模式不结束 explorer，改为藏任务栏（主副屏）、工作区设成整屏，监视循环每 0.1 秒把冒出来的任务栏藏回去；回桌面放回任务栏和工作区。state.json 多了 `covered`（mode=game 且 explorer 在）和 `keepExplorer`。

- 游戏库 `ShellMode.GameMode` 认 covered；模式按钮、快设面板模式键、「退出游戏库」按 GameMode 判断。
- 后台按键路由（ClawRouter-0.17.58-specialkeys.exe，源码 = native/ 下五个文件）：SessionModeProbe 认 covered；FirmwareShortcutFilter 在 covered 时，Win 按下到抬起之间系统没看到别的键（固件的 G/Tab 被吞了）就在抬起前插一个带标记的 Ctrl，开始菜单不弹。原文件留作 `ClawRouter-0.17.58-specialkeys.before-covered.exe`。快捷键测试 23 + 原有项通过。
- 后台 Python：已装的 claw_button_mappings.py 的 session_game_mode 认 covered（只加两行），原件 `claw_button_mappings.py.before-covered`。其余手改文件没动。
- ClawShell 1.0.3 第一版把 `CoverFlagPath` 写成依赖 ShellDir 的静态字段，分部类静态初始化顺序不定 → 启动即崩（状态不写、日志也没有）；改成属性后正常。
- 实测（`artifacts/wm-probe/cov-*.png`）：进游戏模式后 explorer 在、任务栏藏住、TextInputHost 在；单按 Win 不出开始菜单、任务栏不冒；快设面板照游戏模式打开；新窗口被铺满；游戏模式下打 nihao 出「你好」候选框；回桌面任务栏回来。
